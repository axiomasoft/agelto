# Tailwind CSS development

## When to use this skill
Use this skill when implementing or adjusting styling in the frontend (Inertia/Vue, Filament overrides, components).

## Project expectations
- Reuse existing utility patterns and component structure already present in the codebase.
- If styles don’t appear, the user may need to run `npm run dev` / `npm run build`.
