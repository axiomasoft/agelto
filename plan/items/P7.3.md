# P7.3 — Docker/Nginx Hardening, `@sha256:` пины, разделение образов и off-host encrypted бэкапы

## Цель
1. `docker/host/nginx/agelto.conf` + `docker/nginx/default.conf`: выровнять `client_max_body_size 200M` и `proxy_read_timeout 300s`, добавить `proxy_hide_header X-Frame-Options`, вернуть `X-Content-Type-Options: nosniff` в `location`-блоках с `add_header`, добавить `server_tokens off`, HSTS, `ssl_protocols TLSv1.2 TLSv1.3`.
2. `docker/php/Dockerfile` + `docker-compose*.yml`: запинить базовые образы по `@sha256:`, разделить `runtime-base` на лёгкий `app-base` (web/scheduler/4 демона) и `worker-prepare` (LibreOffice/Tesseract/OCR); добавить `no-new-privileges:true` и `stop_grace_period: 30s` на data-сервисы.
3. `docker/scripts/release-deploy.sh`: добавить `--wait` и `IMAGE_REGISTRY`; `docker/scripts/vendor_manifest.py:53`: валидация semver вместо жёсткого `"0.1.0"`.
4. `docker/host/backup/backup-local-enabled.sh` + `docker/scripts/host-provision.sh` + production lifecycle scripts: убрать `--user root`, перейти на `age`/`restic` + off-host копию, устанавливать systemd-обёртки.

## Верификация
1. `bash docker/tests/ingress-backup-contract.sh && bash docker/tests/release-image-contract.sh`
