# Верификация лидов (Human-in-the-loop) — Agelto

> [!note] Назначение
> Процесс премодерации матчей до передачи лида в CRM. Гарантия точности ≥ 92% (NFR [[BRD]] §5), митигация галлюцинаций ИИ ([[Risk_Register]] R-1). Требования — F-MATCH-5/6/7.

---

## Поток

```
Матч (Match Score)
  │
  ├─ confidence ≥ 92% ──→ авто-допуск к лиду → CRM / Radar
  │
  └─ confidence < 92% ──→ флаг «Требует проверки»
        │
        ▼
     Очередь премодерации (Analyst)
        ├─ подтверждён → лид допущен + строка в обучающую выборку
        └─ отклонён   → матч скрыт + строка в обучающую выборку
```

Порог 92% настраивается per-клиент (F-MATCH-6).

## Правила

| Аспект | Правило |
|:---|:---|
| SLA проверки | Цель: ≤ 4 рабочих часа (тендеры с коротким сроком подачи — приоритет). Финально — после P6 |
| Очерёдность | Сортировка: дедлайн подачи ↑, потенциальная сумма ↓ |
| Вердикты | Подтверждён / Отклонён / Отклонён с указанием верного кандидата (топ-3, F-MATCH-3a) |
| Active learning | Все вердикты — в обучающую выборку (F-MATCH-7, цель диплома: 50 000+ размеченных строк) |
| Контроль качества | Выборочная перепроверка N подтверждённых матчей/мес против golden dataset → метрика Accuracy в NFR |
