# Глоссарий

Единый словарь терминов Agelto — и бизнес-понятий (что означает термин из мира госзакупок), и технических имён сущностей (как это называется в системе). Таблицы актуальны на дату этого документа: недавно все таблицы домена закупок были переименованы под единый префикс `prc_` (кроме универсальных справочников `ref_*` и реестра организаций `org_organizations` — они самостоятельные и переиспользуются вне домена закупок). Старые имена (`plt_*`, `doc_*`, `est_*`, `ai_*`, `crw_*`) больше не используются нигде в коде.

## Доменные сущности (актуальный канон)

| Термин | Таблица | Что это |
|---|---|---|
| `Platform` | `prc_platforms` | Площадка-источник данных (сейчас — ЕИС, в перспективе — другие площадки) |
| `Registry` | `prc_registries` | Раздел закупок внутри площадки (44-ФЗ, 223-ФЗ) |
| `Procurement` | `prc_procurements` | Закупка (извещение) — центральная сущность системы |
| `ProcurementRevision` | `prc_revisions` | Снимок состояния закупки на момент обнаруженного изменения — история версий |
| `ProcurementEvent` | `prc_events` | Запись в журнале событий закупки (сменился статус/цена/дата, появился документ и т.п.) |
| `Lot` | `prc_lots` | Лот закупки |
| `PurchaseItem` | `prc_items` | Позиция объекта закупки (товар/работа/услуга) — не путать с позицией сметы |
| `Financing` | `prc_financing` | Источник и сумма финансирования закупки/лота по годам |
| `EisDetails` | `prc_eis_details` | Специфичные для ЕИС поля закупки (ИКЗ, обеспечение заявки/контракта и т.п.) |
| `Protocol` | `prc_protocols` | Протокол закупочной процедуры |
| `Bid` | `prc_bids` | Заявка участника на участие в закупке/лоте |
| `Award` | `prc_awards` | Результат определения победителя по лоту |
| `Clarification` | `prc_clarifications` | Разъяснение по документации закупки |
| `Cancellation` | `prc_cancellations` | Отмена закупки/лота |
| `Organization` | `org_organizations` | Организация (юрлицо) — единый реестр по ИНН/ОГРН, не относится только к закупкам |
| `ProcurementParty` | `prc_procurement_parties` | Роль организации в конкретной закупке (заказчик/участник/победитель и т.п.) |
| `Document` | `prc_documents` | Документ закупки (вложение) |
| `DocumentVersion` | `prc_document_versions` | Конкретный скачанный файл документа (версии дедуплицируются по хэшу содержимого) |
| `Estimate` | `prc_estimates` | Распарсенная смета документа |
| `Estimate\Section` | `prc_estimate_sections` | Раздел сметы (иерархия) |
| `Estimate\Item` | `prc_estimate_items` | Строка (позиция) сметы |
| `Estimate\Resource` | `prc_estimate_resources` | Труд/машины/материалы/накладные по позиции сметы |
| `Estimate\Total` | `prc_estimate_totals` | Итоговые суммы сметы (НДС, накладные, сметная прибыль) |
| `Ai\Analysis` | `prc_ai_analyses` | Сессия AI-анализа документа (скрининг и/или извлечение) |
| `Ai\LlmCall` | `prc_ai_llm_calls` | Технический журнал одного обращения к модели ИИ (токены, стоимость) |
| `Ai\Provider` | `prc_ai_providers` | Доступный провайдер модели ИИ |
| `Ai\AiRoute` | `prc_ai_routes` | Правило маршрутизации: какой провайдер/модель для какого шага/типа документа |
| `Ai\Prompt` | `prc_ai_prompts` | Текст промпта с версионированием |
| `Crawler` | `prc_crawlers` | Профиль обхода конкретного реестра площадки |

## Изменения терминов относительно предыдущей версии продукта

Прежняя (первая) версия системы использовала другие названия для части понятий. Если встречаются старые термины в разговоре или в старых материалах — вот соответствие:

| Старый термин (v1) | Актуальный термин (v2) | Комментарий |
|---|---|---|
| `Link` | `Procurement` (закупка) | В прошлой версии найденная закупка называлась «ссылкой»; сейчас это полноценная сущность закупки |
| `LinkAttachment` | `Document` (документ) | Файл-вложение закупки |
| `DocumentAnalysis` (модель `plt_document_analysis`) | `Ai\Analysis` (`prc_ai_analyses`) | Сессия AI-анализа документа |
| `Order` / `Lot` (нормализация после успешного парсинга) | `Procurement` / `Lot` | В прошлой версии это была отдельная, слабо связанная с остальным пайплайном ветка; сейчас `Procurement` и `Lot` — часть единой модели закупки с самого обнаружения, а не результат отдельной пятой стадии |
| Архивный/backlog-обход | — | Отсутствовал в прошлой версии полностью; появился только сейчас (см. `crawling-and-discovery.md`) |

## Бизнес-термины домена госзакупок

| Термин | Определение |
|---|---|
| **ЕИС** | Единая информационная система в сфере закупок (zakupki.gov.ru) — основной источник данных |
| **44-ФЗ** | Федеральный закон о контрактной системе — государственные закупки |
| **223-ФЗ** | Федеральный закон о закупках госкорпораций и субъектов естественных монополий |
| **Извещение** | Уведомление о закупке в ЕИС, имеет уникальный реестровый номер — в системе это и есть `Procurement` |
| **Реестровый номер (`source_number`)** | Уникальный номер закупки в ЕИС — ключ, по которому система узнаёт «это та же самая закупка» и не создаёт дублей |
| **Лот** | Часть закупки, может содержать несколько позиций объекта закупки |
| **Смета** | Строительно-сметный расчёт — документ с перечнем материалов, объёмов работ и цен |
| **НМЦК** | Начальная (максимальная) цена контракта |
| **ИКЗ** | Идентификационный код закупки — расшифровывается на составные части (год, код заказчика и т.п.) |
| **ОКПД2** | Общероссийский классификатор продукции по видам экономической деятельности |
| **КТРУ** | Каталог товаров, работ, услуг для нужд государственных и муниципальных закупок |
| **ОКВЭД2** | Общероссийский классификатор видов экономической деятельности |
| **КБК** | Код бюджетной классификации |
| **Протокол подведения итогов** | Официальный документ ЕИС с результатом закупки и победителем |
| **Победитель** | Участник, определённый в протоколе подведения итогов |
| **Заявка участника** | Предложение конкретного участника на участие в закупке/лоте, с результатом рассмотрения (допущена/отклонена/выигравшая) |
| **Разъяснение** | Официальный ответ заказчика на вопрос по документации закупки |
| **Отмена** | Закупка (или лот) отменена заказчиком до завершения |
| **Несостоявшаяся закупка** | Закупка, где не выполнены условия конкуренции (нет/мало заявок, все отклонены) |
| **Единственный поставщик** | Неконкурентная закупка (ст. 93 44-ФЗ) — победитель известен заранее |
| **Скрининг** | Первый, дешёвый шаг AI-анализа документа — определение типа и релевантности |
| **Извлечение** | Второй, детальный шаг AI-анализа — построчный разбор содержимого сметы |
| **Скрейпинг / обход / краулинг** | Автоматизированный сбор данных с площадки-источника |
| **Fresh-обход** | Регулярный обход, следящий за свежими изменениями на площадке |
| **Archive-обход** | Разовая перекачка исторического массива закупок за выбранный период |
| **Backlog-рескан** | Точечная повторная перекачка окна времени, которое могло быть пропущено при сбое fresh-обхода |
