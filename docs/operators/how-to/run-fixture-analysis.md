# Запустить разбор эталона («Прогнать»)

## Назначение

Запустить AI-разбор эталонного документа из обучалки вручную — например, чтобы проверить промт
после правки или повторить разбор с учётом коррекции.

## Предусловия

- Роль «Оператор» или «Суперадмин» — кнопка «Прогнать» не видна «Аналитику».
- Открыта карточка эталона в разделе **AI-анализ** → **Эталоны**.
- У эталона нет уже запущенного прогона (кнопка скрыта, пока прогон не завершится).

## Шаги

1. Откройте карточку эталона.
2. Нажмите кнопку заголовка **«Прогнать»** и подтвердите действие.
3. Система покажет уведомление **«Поставлено в очередь»** — разбор запущен тем же путём, что и
   боевой документ (подготовка → скрининг → извлечение), только на копии эталонного файла.
4. Дождитесь завершения — новая строка появится в истории прогонов на карточке эталона (список
   обновляется сам, пока прогон не завершён).
5. В строке нового прогона видно: статус, режим запуска («вручную»), время начала/окончания,
   длительность, а после завершения — токены и цена конкретно этого прогона.
6. Нажмите на строку прогона (или кнопку **«Результат»**), чтобы открыть модалку с разбором:
   - вердикт первичного анализа (тип документа, уверенность, если документ отсеян — причина);
   - сводка того, что извлечено (для сметы — сколько строк, суммы, признаки расхождений);
   - эталонный разбор РЯДОМ с полученным — для визуального сравнения, без возможности править
     эталон отсюда.

## Исключения

- **Кнопка «Прогнать» недоступна («Недостаточно прав»)** — обратитесь к администратору за ролью
  «Оператор».
- **Токены/цена показывают «нет данных»** — прогон ещё не завершился, либо завершился с ошибкой до
  первого LLM-вызова; дождитесь завершения или проверьте статус.
- **В сводке написано «Шаг разбора не выполнялся»** — вердикт первичного анализа не пропустил
  документ дальше (например, документ определён не сметой) — это ожидаемое поведение, не сбой.
- **Прогон запускается, но кнопка «Прогнать» выключена в конфигурации** — AI-разбор глобально
  выключен (`AI_SCREENING_ENABLED`) — эскалируйте разработчику, это техническая настройка.
- Если результат прогона расходится с эталоном заметно — это повод завести предложение по правке
  промта у разработчика (`manage-prompts.md`), а не признак поломки самого прогона.

## Результат

Разбор эталона запущен и проверен вручную, результат сравнён с эталонным разбором на одном экране,
без обращения к консоли или логам.
