# Проверить помеченные позиции сметы

## Назначение

Быстро найти позиции сметы, которые AI (или проверка сметы) считает ненадёжными, и понять,
почему именно — не открывая карточку каждого AI-анализа по отдельности.

## Предусловия

- Любая роль, кроме «Аналитика», видит витрину смет как минимум на просмотр (мини-матрица прав —
  `operators/_index.md`); «Оператор»/«Суперадмин» видят то же самое, витрина read-only для всех
  ролей одинаково.

## Шаги

1. Откройте раздел «Сметы» в админке. Список смет несёт колонку «Помечено N из M» — сколько
   позиций сметы имеют пометку неопределённости из общего числа позиций.
2. Отсортируйте/найдите смету с ненулевым счётчиком.
3. Откройте смету — на странице просмотра позиций включите фильтр «Только помеченные».
4. У каждой отфильтрованной строки — колонка «Пометка» несёт причину по-русски и перечень полей,
   которых она касается (`reference/statuses.md` — расшифровка причин: «не прочитано моделью» /
   «арифметика раздела не сходится» / «нарушена нумерация строк»).
5. Сверьте помеченные поля с оригиналом документа (тот же приём, что для «подозрительной» сметы
   целиком — `how-to/review-estimate.md`).

## Что здесь НЕЛЬЗЯ сделать

Витрина смет **read-only**: снять пометку, поправить значение позиции или подтвердить строку
отдельно от сметы отсюда нельзя — ни кнопки, ни формы правки на этой странице нет. Если после
проверки по оригиналу документа значение действительно неверно — это тот же путь, что и для
сметы целиком: «Отклонить с коррекцией» на карточке AI-анализа (`how-to/review-estimate.md`), не
через витрину смет. Точечная правка самой позиции оператором в системе сегодня не предусмотрена
(открытый вопрос будущей фазы, не эта витрина).

## Результат

Понятно, какие позиции сметы требуют внимания и почему, без необходимости пересчитывать смету
руками или листать все AI-анализы подряд.
