# Конкурентный анализ

> Часть бизнес-концепции продукта — см. [[concept-and-monetization]] для проблемы/решения/тарифов.

## Конкурентный ландшафт

Рынок тендерных сервисов в РФ — в основном системы «первого поколения» с атрибутивным поиском (по названию контракта, по ИНН заказчика):

| Игрок | Суть | Слабость относительно подхода Agelto |
|---|---|---|
| Seldon | Крупнейший агрегатор ЕИС | Поиск по названию контракта/ИНН, нет разбора содержимого смет |
| Тендерплан | Уведомления о тендерах | Тот же атрибутивный поиск, нет ИИ-разбора содержимого |
| Контур.Закупки | Широкая экосистема | Широкий охват, но нет глубокой декомпозиции смет |
| Бикотендер и аналоги | Мониторинг закупок | Базовый поиск, без семантики |
| РТС-тендер | Электронная торговая площадка | Площадка проведения торгов, а не аналитический инструмент |

**Незанятая ниша:** глубокий AI-разбор содержимого смет строчка за строчкой с последующим семантическим сопоставлением с каталогом конкретного поставщика.

Разница в подходе:

```
Конкуренты: находят ТЕНДЕР → поставщик сам читает смету (часы/дни)
Agelto:     находит СТРОКУ В СМЕТЕ → сопоставляет с прайсом → доставляет как лид (секунды)
```

## Барьеры входа (защита от копирования)

1. **Технологический** — конвейер разбора неструктурированных смет (сложное сочетание распознавания структуры документа, ИИ-извлечения и последующего сопоставления) требует значимого времени разработки и инвестиций.
2. **Данные** — накопленный набор проверенных, размеченных разборов реальных смет: конкурент может скопировать общий справочник товаров/услуг, но не накопленную историю качественных вердиктов по конкретным сметам.
3. **Доменная экспертиза** — понимание специфики сметной документации и особенностей конкретных товарных направлений (ЖБИ, кабель, металлопрокат) нарабатывается только на практике.

## Возможности и риски рынка

**Возможности:** государственный вектор на цифровизацию строительной отрасли; потенциальная интеграция с государственными цифровыми платформами; расширение в смежные области (например, информационное моделирование зданий — связь цифровой модели с рынком материалов); функция антикоррупционного аудита смет (сверка заявленных цен с рыночными).

**Риски:** крупные игроки рынка могут выпустить упрощённую версию похожего функционала; источник данных (ЕИС) может изменить порядок доступа к документам; дефицит специалистов по обработке естественного языка и машинному обучению на рынке труда; качество исходных PDF-документов в самой ЕИС не всегда высокое, что усложняет автоматический разбор.
