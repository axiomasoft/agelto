# Финансовая модель и ресурсный план — Agelto

> [!note] Источник
> Выжимка из дипломной работы (гл. 2.3, 3.1–3.3), оригинал — архив `assets/_Диплом v1.1.docx`. Тарифная сетка — [[BRD (Agelto)]] §7.1, риски — [[Risk_Register (Agelto)]].

## 1. Модель монетизации

Три потока дохода:
1. **Подписка (MRR)** — базовая плата за платформу (тарифы Start 25к / Business 75к / Enterprise от 200к ₽/мес — детали в [[BRD (Agelto)]] §7.1)
2. **Usage-based** — оплата декомпозиции смет сверх лимита тарифа (pay-per-lead)
3. **Setup & Professional Services** — разовая интеграция «под ключ» (CRM, обучение) — [[Onboarding]]

**Freemium Light (запуск 2026):** бесплатный доступ к списку тендеров с декомпозицией только 3 первых позиций сметы — демо точности. ⚠️ Конфликтует с BRD F-MON-2 — резолюция: [[Открытые вопросы (Agelto)]] P5.

**Success Fee** (комиссия за крупные закрытые сделки) — вспомогательная модель, за горизонтом 3-летнего плана.

## 2. ROI-аргумент для продаж

Сметчик-аналитик: ~120 000 ₽/мес (с налогами и местом), обрабатывает 40–60 сложных смет/мес. Тариф Business (75 000 ₽) — до 300 смет/мес: **в 5–6 раз больше объёма за 60% стоимости сотрудника**. Окупаемость для клиента — первый месяц.

| Показатель | Значение |
|:---|:---|
| NPV | **23,3 млн ₽** |
| PI | 2,03 |
| IRR | 48,5% |
| DPP | конец 3-го года (кумулятивный DCF: −19,9 → −42,5 → −29,6 → **+3,4** млн ₽) |

## 6. Чувствительность и стресс-границы (NPV = 0)

| Фактор | Изменение | ΔNPV | Эластичность | Риск |
|:---|:---|:---|:---|:---|
| Выручка (подписки) | −20% | −38% | 1,9 | 🔴 критическая |
| CAPEX | +20% | −18% | 0,9 | средняя |
| OPEX | +20% | −12% | 0,6 | низкая |

Пределы прочности: цена подписки −35% (Business ниже 48к ₽ — не окупается за 3 года) · CAPEX +45% · churn 15%/мес → операционный убыток. **Главный риск — коммерческий (объём продаж), не технический.**

Сценарии: оптимистичный 45,2 млн ₽ (P=20%) · базовый 23,3 (P=60%) · пессимистичный 4,8 (P=20%).

## 7. Команда и ресурсы

Модель «Core Team + Outstaff», 3 стрима:

| Стрим | Состав |
|:---|:---|
| AI/ML | Lead Data Scientist ×1, NLP/OCR Engineer ×2 |
| Платформа и данные | Senior Backend ×1, Data Engineer/Architect ×1, Frontend ×1 |
| Продукт и бизнес | Product Manager ×1, DevOps ×0.5 (outsource) |

Фазы найма: M1–M3 R&D (бюджет найма 1,2 млн ₽, прототип ядра) → M4–M6 Product (0,8 млн ₽, интерфейс + CRM + пилоты) → M7+ Scale (0,5 млн ₽, продажи и поддержка).

**Инфраструктура:** аренда GPU (дообучение моделей) + CPU-кластеры (inference), PostgreSQL+pgvector, Redis, **S3-совместимое хранилище для оригиналов PDF/XLS** (→ [[Architecture_Agelto]] §13). Диверсификация облаков (Yandex Cloud / Cloud.ru / Selectel) + Reserved Instances — митигация [[Risk_Register (Agelto)]] R-6/R-7.

**База знаний** (критический актив): нормативные коллекции КТРУ/КСР (регулярное обновление — BRD F-MDM), обучающая выборка 50 000+ размеченных строк, пользовательские прайс-листы.

## 8. Региональный / GTM-аргумент для гос-сегмента

- +25–30% участников на лот (ликвидация «скрытых» позиций в сметах) → рыночное ценообразование
- Экономия до 5–7% НМЦК для бюджета за счёт роста конкуренции
- Уведомления локальным заводам о закупках «их» продукции → рост местного производства и налоговой базы

Аргументы для продаж через программы цифровизации регионов и анти-коррупционную повестку.
