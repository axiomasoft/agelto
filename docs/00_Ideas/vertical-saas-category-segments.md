# Vertical-SaaS по узким сегментам (ЖБИ / кабель / металлопрокат)

## Обзор

Вместо «горизонтального Agelto для всех стройматериалов» — пачка узких
вертикалей, каждая со своим per-category dashboard и доменными бенчмарками.

Гипотеза: закупщик ЖБИ и продавец кабеля смотрят разные метрики, разную
нормативку, разные типоразмеры. Универсальный дашборд = посредственный для всех.
Вертикаль = killer-продукт для одного сегмента.

Каждая вертикаль:

- **Нормализованный классификатор**: ОКПД2 → ГОСТ → техпараметры (класс бетона,
  диаметр арматуры / сечение и тип изоляции кабеля / марка стали и типоразмер
  проката). Иерархия раздел→группа→подгруппа→товар для агрегации.
- **Per-category dashboard**: объём закупок по месяцам (натуральный + рублёвый),
  топ заказчиков и поставщиков, средние цены по ГОСТ/типоразмеру.
- **Бенчмарки GOST/ОКПД2**: справочные ценовые коридоры по типоразмеру, флагование
  аномальных закупок (дорого/дёшево к медиане), рекомендуемая цена.

Wedge: первая опора — один сегмент с лучшей доступностью данных (вероятно
металлопрокат: открытые прайс-листы + статистические порталы цен).

## Рыночное подтверждение

> Источник: perplexity-web (2026-06-22).

- **ЖБИ — измеримый рынок**: производство сборных ж/б фундаментов 2024 — **~1,223
  млн м³**; объём рынка ЖБИ янв-2022 — **19,3 млрд ₽** (+16,7% к янв-2021).
  Среднегодовой спад выпуска 2017–2024 ~4,9% (рынок зрелый, не растущий).
  Цена производителя дек-2024 «фундаменты сборные ж/б» — **~17 300 ₽/м³**.
  Источники: tk-solutions.ru, vk.com/cm_pro_analytics.
- **Кабель**: спец-обзоры рынка КПП существуют, но цифры часто за paywall →
  лучшая прокся = реал-тайм закупки по **ОКПД2 27.32** через агрегаторы (метры +
  рубли). Источники: imrg.ru, energybase.ru.
- **Металлопрокат**: открытые статистические порталы публикуют динамику цен по
  сортам (лист г/к, х/к, трубы, уголок, швеллер); металлобазы — онлайн-прайсы с
  привязкой к ГОСТ и маркам стали. ГК «Тантал» декларирует миллионы SKU →
  масштаб рынка. **Лучшая доступность данных для MVP-бенчмарков.** Источники:
  metalinfo.ru, mzstal.ru, tantal-metall.com.
- **ОКПД2+ГОСТ как каркас данных подтверждён**: отчёты и тендерные агрегаторы уже
  группируют по этим кодам; формат кода даёт готовую иерархию для аналитики.
  Источники: gos-tender-ai.ru, zakupki44fz.ru.
- **Плотность дистрибьюторов**: отраслевые каталоги металлорынка содержат сотни
  компаний; отдельный пул кабельщиков («Кабель-Сити», «КабельПлюс»,
  «Кама-КабСнаб» и др.). Источник: metalinfo.ru.

> Ограничение: рынок данных фрагментирован, часть объёмов за paywall.
> Точные рублёвые объёмы кабеля — market-check TODO (нужен платный отчёт или
> агрегация ЕИС по 27.32).

## Связь с проектами

- [[Agelto]] — переиспользует pipeline и SmetaParserService; вертикаль = профиль
  PromptRules + специализированный дашборд поверх общего ядра.
- [[TcenZor]] — каталог должен поддержать доменные техпараметры по сегментам
  (класс бетона / сечение / марка стали), иначе бенчмарки не построить.
- [[white-label-distributor-platform]] — вертикали можно продавать
  дистрибьюторам как уже-настроенные white-label пресеты.

## Риски

- **Фрагментация спроса**: 3 вертикали = 3 раза product discovery, 3 пайплайна
  данных. Распылиться. Начать строго с одной (металлопрокат — лучшие данные).
- Источники бенчмарк-цен частично за paywall → возможны лицензионные косты или
  необходимость строить цены из ЕИС-закупок самостоятельно.
- Доменные техпараметры в каталоге [[TcenZor]] — может потребовать расширения
  схемы каталога (зависимость).

## Следующий шаг

Promote-критерий: выбрать **одну** опорную вертикаль (гипотеза: металлопрокат) и
проверить полноту данных — собрать ОКПД2-срез закупок + открытые ценовые ряды за
3 мес, прикинуть качество бенчмарков. Если бенчмарк строится на открытых
данных без paywall → `/vault:prd` на первую вертикаль.
