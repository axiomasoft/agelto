# Перезапуск упавшей обработки

Здесь будет SOP диагностики и перезапуска упавшей обработки, включая раздел
«не смогли обработать документ» (`unprocessable`, D32): причины, можно ли разбить/пересжать,
когда эскалировать разработчику.

Наполняется в P10.4.
