# Проверить результат AI-разбора документа

## Назначение

Посмотреть, что система извлекла из конкретного документа (или почему не извлекла), не заходя в
исходный файл вручную.

## Предусловия

- Роль «Аналитик», «Оператор» или «Суперадмин» — просмотр раздела «AI-анализ» доступен всем трём.
- Известен документ (или закупка), по которому нужен результат.

## Шаги

1. Откройте раздел **AI-анализ** → **AI-анализы** в админке.
2. Найдите нужную запись — поиск по названию документа (колонка «Документ»), или отфильтруйте по
   шагу (`step`: скрининг/извлечение) и статусу (`status`).
3. Откройте карточку записи (просмотр). На карточке видно:
   - какой документ анализировался и на каком шаге;
   - статус анализа и статус ревью;
   - тип документа, определённый скринингом (если применимо);
   - при извлечении — список смет из этого анализа: номер, статус полноты (`validation_status`),
     сколько строк ожидалось/извлечено;
   - при ошибке — текст последней ошибки.
4. Если нужен «сырой» ответ модели целиком — он тоже показан на карточке (поле «Result»), в
   формате JSON.

## Исключения

- **Анализа нет вообще** — документ ещё не дошёл до этой стадии (проверьте
  `04_Operators/reference/statuses.md` для статуса самого документа) или был отсеян раньше
  (`ignored`) — в этом случае AI-анализ мог не запускаться.
- **Статус `failed`** — система обычно повторяет попытку автоматически; если статус не меняется
  долго — см. `restart-failed-run.md`.
- **Статус документа `unprocessable`** — анализ принципиально не будет запущен повторно
  автоматически — см. `handle-unprocessable-document.md`.

## Результат

Понятно, что система нашла в документе (или почему не нашла), без обращения к разработчику.
