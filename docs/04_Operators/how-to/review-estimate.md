# Ревью сметы

Здесь будет SOP петли ревью (P9.2): галочка «проверено» / коррекция «что не так» / перезапуск;
объяснение `validation_status=suspicious` словами оператора («суммы не сходятся — проверьте
раздел N»).

Наполняется в P10.4.
