# Как править документацию

## Где что живёт

- `docs/` — единое дерево документации, целиком зеркалится в Obsidian-vault Brain
  (`~/Vaults/Brain/.projects.json` задаёт связку проекта с vault'ом), включая реальную экономику,
  лимиты, глубокую промт-инженерию и риски по решению владельца D89.
- Каркас разделов (что за что отвечает, куда класть новый файл) — живой
  [канон структуры](structure.md). Новый верхнеуровневый раздел — сначала решение владельца,
  затем файл.
- Связный контракт извлечения смет живёт в
  [`docs/dev/ai/estimate-extraction.md`](../dev/ai/estimate-extraction.md); факты о других
  подсистемах — в их канонических разделах `business/**` и `dev/**`.

## Frontmatter — обязателен в каждом файле

```yaml
---
audience: dev | operator | owner | shared
type: howto | reference | explanation | runbook | adr
status: draft | living
last-reviewed: YYYY-MM-DD   # только для SOP (operators/how-to/**)
---
```

`status: draft` — заглушка с аннотацией «что здесь будет»; `status: living` — раздел наполнен и
поддерживается. `last-reviewed` обновляйте при каждой содержательной правке SOP.

## Диаграммы

Mermaid — инлайн в markdown-файле (рендерится и GitHub, и Obsidian), отдельные файлы только для
диаграмм с двумя и более использованиями в разных документах. Известный gotcha: `stateDiagram-v2`
не парсит `::` в некавычечной edge-метке — используйте `Class.method()`, а не `Class::method()`,
в подписях переходов (в sequence/flowchart-диаграммах и в кавычечных `"..."`-метках `::` не
ломается).

## Один канонический документ

Никаких копий текста между разделами — только ссылки. Пример: `resources/ai/prompts/README.md` —
единственный источник «как писать промт», `dev/ai/prompts.md` на него ссылается, не копирует.

## PR-чеклист

Правило сформулировано как source в `.ai/guidelines/docs-pr-checklist.md` — применяется ко ВСЕМ
PR: «docs обновлены?», и отдельно для правок Filament-ресурсов — «операторский SOP обновлён?».

## Brain-sync

Верхние категории — `ideas`, `business`, `workflow`, `dev`, `operators` и `meta`:
нижний регистр, без числовых префиксов. Переименование утверждено владельцем 2026-09-13.
Всё дерево `docs/` зеркалится в Obsidian-vault Brain; при следующей синхронизации необходимо
согласовать новые имена с vault, не создавая дубликаты старых разделов. Изменение дерева в Git
само по себе не доказывает, что внешний vault уже обновлён. Следующие переименования требуют
решения владельца.
