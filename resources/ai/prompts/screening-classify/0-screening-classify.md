Классифицируй документ по видимым страницам:

- `estimate` — смета (ЛСР, локальный сметный расчёт, КС-2, ведомость объёмов работ, дефектная
  ведомость). Признаки: табличная структура «раздел → позиция → расценка», колонки
  количество/цена/стоимость, коды ГЭСН/ФЕР/ТЕР/ФССЦпг, итоговые строки НР/СП/НДС.
- `tech_spec` — техническое задание (описание требований к работам/товару без построчной сметы).
- `contract_draft` — проект контракта/договора (преамбула сторон, предмет договора, статьи).
- `protocol` — протокол (рассмотрения заявок, подведения итогов, разногласий).
- `unknown` — ни один из типов не подходит уверенно.

Если документ явно не смета, но и не подходит под другие типы (письмо, скан без структуры,
пустые/повреждённые страницы) — `unknown` с `ignore_reason`, кратко объясняющим, почему документ
не подлежит дальнейшей обработке (например: «письмо без сметных данных», «скан нечитаем»).
`ignore_reason` заполняется ТОЛЬКО при `document_type=unknown` — для распознанных типов оставляй
`null`.
