Найди «паспорт» сметы — данные шапки, не построчные позиции. Ищи в первых страницах документа
(титул, шапка ЛСР/КС-2):

- `estimate_number` — номер сметы, если указан («Смета №...», «ЛСР №...»).
- `passport` — тип сметы, обоснование/шифр, наименование объекта/направление работ, адрес,
  программа-генератор сметы (если в подвале/колонтитуле есть указание — «Составлено в программе
  ...»).
- `currency` — код валюты (по умолчанию `RUB`, если не указано иное).
- `base_year` — базовый год цен, если указан явно (например «в ценах 2001 г.» для ФЕР).
- `price_level` — текстовое указание уровня цен, если оно не сводится к простому году
  («текущие цены на IV кв. 2025»).
- `rows_expected` — твоя ОЦЕНКА числа позиций (не разделов, не подытогов) во всей смете по видимым
  признакам (напечатанная нумерация позиций до последней, оглавление разделов) — это ориентир для
  контроля полноты на бэкенде, не обязана быть точной до единицы.
- `totals` — заполняй ТОЛЬКО если подвал сметы (НР/СП/НДС/итого) физически попал в тот же контекст,
  что и шапка; иначе оставь `null` — итоги запрашиваются отдельным шагом.

**Реквизиты акта.** У актов (КС-2, КС-3) над таблицей стоит титульная таблица реквизитов: номер
документа, дата составления и отчётный период идут отдельными графами — раскладывай их в
`document_number`/`document_date`/`period_start`/`period_end`. Строка «Договор подряда (контракт)»
титула несёт номер и дату ДОГОВОРА — это `passport.contract_number`/`contract_date`. Не смешивай
три разных номера: номер сметы (`estimate_number`), номер акта (`document_number`) и номер
договора.

**`calc_method`.** Бери из титула («Составлен ... методом»). Если документ называет
метод, которого нет среди допустимых значений схемы (например «ресурсно-индексным»), — оставь
`null`, не подгоняй под ближайший похожий.

**Сводные трудозатраты.** `labor_hours_workers`/`labor_hours_machinists` заполняй только из
сводного блока итогов («Справочно: затраты труда рабочих / затраты труда машинистов») — не
суммируй построчные трудозатраты позиций сама.

**Нормативная база сметы.** Паспортный блок формы 421/пр над таблицей позиций несёт три отдельных
реквизита нормативных документов — не путай их с `passport.reference` (основание составления
сметы, строка «Основание»: проектная/техническая документация, задание, договор): «Наименование
редакции сметных нормативов» → `regulatory_base`; «Реквизиты приказа ... об утверждении дополнений
и изменений к сметным нормативам» → `passport.regulatory_amendments`; «Реквизиты письма ... об
индексах изменения сметной стоимости строительства...» → `passport.index_letter`. Каждое поле —
цитата документа как напечатана (может перечислять несколько приказов через «;»), не разбирай её
в дату/номер отдельно. Строки в документе нет — оставь `null`.

**Несколько смет в документе.** Ты ищешь паспорт ровно ОДНОЙ сметы — той, чей порядковый номер
(счёт от начала документа) называет запрос. Не переноси в ответ реквизиты соседних смет (в книге
— соседних листов). Если сметы с запрошенным порядковым номером в документе нет — верни
`estimate_number = null` и `rows_expected = 0`: это штатный ответ «смет больше нет», а не ошибка.

Не переноси сюда построчные позиции — они не относятся к паспорту.
