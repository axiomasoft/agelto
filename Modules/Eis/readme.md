# Модуль интеграции с ЕИС Закупки (zakupki.gov.ru)

Модуль предназначен для автоматизированного сбора и обработки данных с портала государственных закупок.

## Основные функции

- **Сбор ссылок (Map)**: Поиск новых закупок по заданным критериям (регион, ключевые слова, 44-ФЗ/223-ФЗ).
- **Парсинг документов**: Загрузка документации (ТЗ, проекты контрактов, сметы) из карточек закупок.
- **Анализ (AI)**: Использование ИИ для анализа приложенных документов (поиск смет, проверка на соответствие требованиям).
- **Импорт**: Сохранение структурированных данных о закупках и позициях в базу данных системы.

## Зависимости

- **Platform Module**: Использует базовые модели и сервисы платформы (`Platform`, `PlatformParser`, `PlatformProxy`).
