# Document Prepare Process

## Порядок выполнения: 2

Процесс отвечает за физическую обработку файлов и их приведение к унифицированному PDF-формату для ИИ.

## Ответственность

1. **Сохранение исходников**: Загрузка файлов по ссылкам, полученным на этапе кроулинга.
2. **Конвертация**: Преобразование Excel/Word в PDF.
3. **Распаковка**: Рекурсивная обработка ZIP-архивов с созданием дерева записей.
4. **Унификация**: Подготовка "чистого" PDF-слоя для анализа.

## Основные классы

- `DocumentProcessor`: Входная точка (fromModel, fromUrl).
- `Strategies/`: Набор стратегий обработки (ExcelStrategy, ArchiveStrategy).

## Расширение

Для поддержки нового формата:

1. Создайте Strategy класс в папке `Strategies/`.
2. Добавьте его в конфиг `platform.document_prepare.strategies`.
