# Document Analysis Process (Base)

## Порядок выполнения: 3

Базовый слой взаимодействия с Gemini API. Отвечает за транспорт и кэширование данных в облаке.

## Ответственность

1. **Синхронизация**: Загрузка PDF в Google File API и контроль статуса `ACTIVE`.
2. **Кэширование**: Хранение `google_file_uri` для исключения повторных оплат за загрузку (TTL 48ч).
3. **Управление промптами**: Слияние глобальных правил и локальных инструкций.
4. **JSON-гарантия**: Принудительная типизация ответов ИИ.

## Основные классы

- `GeminiService`: Низкоуровневая обертка над API и прокси.
- `PromptRuleRepository`: Менеджер правил из базы данных.
