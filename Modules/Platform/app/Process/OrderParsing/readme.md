# Detailed Procurement Parsing

## Порядок выполнения: 5

Глубокое извлечение данных закупки, лотов и поставщиков из подтвержденных сметных документов.

## Ответственность

1. **Извлечение данных**: Полный парсинг данных поставщика, структуры лотов и спецификаций.
2. **Анализ изменений**: Поиск и структурирование всех значимых изменений в закупке.
3. **Финальная интеграция**: Обновление бизнес-моделей проекта распарсенными данными.

## Основные классы

- `DetailedParsingProcessor`: Процессор глубокого анализа.

## Порядок выполнения

Запускается строго после того, как этап №4 (Primary Analysis) подтвердил наличие данных.
