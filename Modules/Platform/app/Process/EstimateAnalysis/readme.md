# Estimate Primary Analysis

## Порядок выполнения: 4

Экспресс-фильтр для быстрого поиска релевантных смет внутри подготовленных документов.

## Ответственность

1. **Фильтрация**: Анализ первых страниц документа (обычно до 3-х) на наличие сметных таблиц.
2. **Экономия токенов**: Принятие решения о целесообразности глубокого парсинга файла.
3. **Маркировка**: Установка флагов наличия смет для всей закупки.

## Основные классы

- `PrimaryAnalysisProcessor`: Процессор-координатор фильтрации.

## Расширение

Для уточнения критериев поиска:

1. Добавьте новые Prompt Rules в БД для группы `PrimaryAnalysis`.
