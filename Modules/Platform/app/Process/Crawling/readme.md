# Crawler Process

## Порядок выполнения: 1

Процесс отвечает за первичный сбор данных из внешних источников и их импорт в систему.

## Ответственность

1. **Сбор ссылок**: Поиск новых закупок и аукционов на целевых площадках.
2. **Получение метаданных**: Первичное сохранение ключевых характеристик (названия, суммы, даты).
3. **Инициализация**: Создание корневых моделей в БД, которые станут триггерами для следующих этапов.

## Основные классы

- `CrawlerProcessor`: Главный координатор процесса сбора.
- `Parsers/`: Парсеры под конкретные площадки.

## Расширение

Для добавления новой площадки:

1. Создайте соответствующий Parser класс.
2. Зарегистрируйте его в списке источников кроулера.
