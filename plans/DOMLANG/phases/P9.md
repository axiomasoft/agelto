# P9 — Финальный cross-phase review

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design DOMLANG P9

Терминальная фаза. Проверяет не отдельные item'ы (их закрывали пофазные review-гейты), а
**связность результата всего плана**: не разошлись ли глоссарий и код после ренейма P3, закрыт ли
spec drift на самом деле, не появились ли новые мёртвые имена, исполнены ли ADR-0006/0007/0008
буквально.

Три уровня:

1. **P9.1** — cross-phase adversarial review (opus/xhigh): fan-out по измерениям → независимая
   верификация находок → вердикт GREEN / ATTENTION / RED. Образец харнесса —
   скилл `estai-milestone-review`.
2. **P9.2** — `/task:plan-audit DOMLANG Pn` по каждой закрытой фазе: сверка 🟢 с git-фактами,
   поиск no-op-закрытий и scope drift.
3. **P9.3** — `/code-review ultra` — **запускает владелец**. Команда user-triggered и billed;
   агент её не инициирует (D9). Item закрывается только после того, как владелец подтвердил
   прогон и его находки разобраны.

**Scope Included:** проверка связности; adversarial-верификация находок; plan-audit фаз;
приёмка `/code-review ultra`.
**Scope Excluded:** написание нового прикладного кода — находки уровня Blocker возвращаются в
свою фазу через reopen (`🟢`→`🟡` + bump Version + запись в D-лог), а не чинятся здесь.
