# P7 — Глоссарий v2 + OCDS mapping

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design DOMLANG P7

Два глоссария уже существуют (`.ai/guidelines/glossary.md` — технический канон-SSOT;
`docs/02_Workflow/glossary.md` — бизнес-версия, ссылается на первый). Аудит ошибочно рекомендовал
их «завести». Фаза их **дополняет**, а не создаёт.

Отсутствующие термины (проверено): `revision`, `event`, `projection`, `provenance`, `quality flag`,
`notice`, `registry number`, номер ЭТП. Существуют только как имена таблиц/колонок в спеке.

Второй Deliverable — `docs/03_Dev/ocds-mapping.md`. `RAG:✅ 2026-07-10 «OCDS 1.2»`: Open Contracting
Data Standard — де-факто отраслевой стандарт публикации закупочных данных
(`release` / `record` / `compiledRelease` / `versionedRelease` / `ocid`; секции
`planning`/`tender`/`award`/`contract`/`implementation`). Проект уже реализовал изоморф:
`prc_procurements` ≈ compiledRelease, `prc_revisions` ≈ versionedRelease, `prc_events` ≈ releases.
Per ADR-0007 (D3) OCDS — **экспортный контракт, persistence на нём не строим**.

Завершение фазы: оба глоссария покрывают недостающие термины; mapping-таблица существует и явно
объявляет OCDS экспортным слоем.

**Scope Included:** дополнение двух глоссариев; новый `docs/03_Dev/ocds-mapping.md`.
**Scope Excluded:** реализация OCDS-экспортера (кода в фазе нет); переименование внутренних
сущностей под OCDS (запрещено ADR-0007).
