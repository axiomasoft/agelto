### P9.8 — Сводная навигация, канон каркаса и финальная сверка

**Intent:** Собрать входные точки под две аудитории, перенести канон каркаса доков из архивного
плана в живой `docs/meta/structure.md`, включить в гейте свойство «нет файлов-сирот» и провести
финальную сверку дерева.
**Why:** После четырёх переносов дерево изменилось сильнее, чем любая отдельная правка: исчезли два
каталога, появились шесть новых файлов, переехал канон извлечения. Навигация (`docs/index.md`,
`_index.md` разделов) описывает СТАРОЕ дерево и без пересборки будет отправлять читателя в
несуществующие места. Отдельно чинится дефект адресации: живой канон структуры доков сегодня лежит
в АРХИВНОМ плане (`docs/meta/editing.md` отправляет за раскладкой в
`plans/archive/2026.07.07-EST-AI/research/H-docs-structure.md`), то есть у правил каркаса нет
легального места записи (`RAG:— (repo-grounded: docs/meta/editing.md §«Где что живёт»)`).
**Scope Included:** (1) `docs/index.md` — таблицы «Для кого что читать» и «Быстрые ссылки»
пересобраны по фактическому дереву, карта разделов актуальна, диаграмма **Д15** (аудитория →
раздел → входная страница, `flowchart`); (2) `_index.md` каждого раздела (01–04) — состав и
маршруты по факту, ≤7 ссылок на блок; (3) `docs/meta/structure.md` (новый) — канон каркаса:
что за раздел, что в него класть, чего в нём не бывает, правило frontmatter, правило диаграмм,
Brain-sync; `docs/meta/editing.md` ссылается на него вместо архивного плана; (4) свойство «нет
файлов-сирот» в `tests/Unit/Docs/DocsIntegrityTest.php` — каждый файл достижим из `docs/index.md`
по цепочке ссылок; (5) ревизия `status:` в frontmatter: `draft` остаётся только у фактических
заглушек; (6) финальная сверка — счётный замер после фазы против `artifacts/P9-docs-baseline.json`
(сколько файлов было, сколько стало, куда делись удалённые).
**Scope Excluded:** переименование верхнеуровневых категорий `00_Ideas`…`04_Operators` (Brain-vault
ждёт их по именам — решение, затрагивающее внешнюю систему) · заведение пятого раздела (решение
владельца D92) · правка `~/Vaults/Brain/.projects.json` · новые диаграммы сверх Д15 · дописывание
разделов за другие фазы.
**Inputs:** замер «до» — `artifacts/P9-docs-baseline.json` (P9.1) · канонический каркас-источник —

**Implementation Rules:** 1) Навигация проверяется ПРОХОДОМ, а не составлением: каждая ссылка
открывается, каждый раздел достижим из `index.md` максимум в два клика. 2) Свойство «сироты»
включается ПОСЛЕ пересборки навигации, иначе оно красное по построению; при первом включении
допускается ровно один проход «нашли сироту → добавили ссылку», без ослабления правила.
3) `docs/meta/structure.md` — САМОСТОЯТЕЛЬНЫЙ документ, а не пересказ архивного файла со ссылкой на
него: архив может быть недоступен читателю, и именно поэтому канон переезжает. 4) `status:`
меняется только после чтения файла (Л-9). 5) Верхнеуровневые имена не трогаются (Л-8).
6) Финальный замер снимается ТОЙ ЖЕ командой, что и baseline, — иначе числа несравнимы.
**Code Guidance:** Единственное касание PHP — добавление третьего свойства в существующий тест;
форма та же (Finder + рукописные константы). **Запрещённые shortcuts:** «сироты» через белый список
файлов вместо реального обхода ссылок; копирование `H-docs-structure.md` в `meta/structure.md`
дословно вместе с устаревшими адресами; правка `CLAUDE.md` без правки `.ai/guidelines/**`;
объявление фазы завершённой при красном гейте. **Анти-самообман:** «дерево целостно» доказывается
зелёным гейтом с ТРЕМЯ свойствами и счётной сверкой «было / стало / удалено», а не обходом
глазами; оба числа — в Completion Notes с якорем на bookkeeping-коммит. **Анти-подгонка:** сирота
не лечится исключением в тесте — либо на файл появляется ссылка, либо файл удаляется как ненужный
(с причиной).
**Validation:** гейт с тремя свойствами зелёный —
`docker compose exec -e DB_DATABASE=agelto_test app php artisan test --no-tia --filter='DocsIntegrity'`
— ≥4 теста · исключений нет — `grep -cE "docs-private|specs/v2" tests/Unit/Docs/DocsIntegrityTest.php`
= 0 · канон каркаса живой — `ls docs/meta/structure.md` без ошибки и
`grep -c "plans/archive" docs/meta/editing.md` = 0 · сверка сходится — числа
`artifacts/P9-docs-final.json` против `artifacts/P9-docs-baseline.json` объяснены до последнего
файла (перечень удалённых с адресом, куда ушёл факт) · заглушек не осталось лишних —
`grep -rl "status: draft" docs | wc -l` названо числом и каждый оставшийся `draft` объяснён ·
полный прогон `--no-tia` зелено · `pint --test` и
`phpstan analyse --memory-limit=1G` — зелено, без роста baseline
**Deliverables:** пересобранный `docs/index.md` с Д15 и пять актуальных `_index.md` ·
