### P2.5 — Команда пересборки карты с ЕИС и детект дрейфа id

**Intent:** Дать способ пересобрать карту «код → id НСИ» с площадки и УВИДЕТЬ дрейф: консольная
команда обходит `children.html` от заданного корня, сверяет снятое с сохранённым и отчитывается
добавленным/исчезнувшим/изменившим id; если изменился или исчез код, использованный АКТИВНЫМ
профилем, — команда завершается ненулевым кодом.
**Why:** Стабильность внутренних id справочника НСИ во времени доказать одним замером невозможно,
поэтому обязанность вынесена из «замерить» в «детектировать в рантайме» (D14), а от id зависит
выборка целиком: подменившийся id даёт МОЛЧА неверную выдачу — запрос успешен, `totalCount`
правдоподобен, а закупки не те. `RAG:— (repo-grounded: plan.md D14;
findings/P1-okpd2-probe.md §6 п. 1)`. Источник карты подтверждён живым замером:
`GET /epz/api/nsi/okpd2/children.html?parentId=<id>` отдаёт детей узла, корневой уровень — 21
раздел. `RAG:✅ 2026-08-06 (findings/P1-okpd2-probe.md §5)`.
**Scope Included:** (1) команда `App\Console\Commands\Procurement\SyncOkpd2Nodes` с сигнатурой
`crawler:okpd2-sync {--root=} {--dry-run} {--max-requests=}` (дефолты корня и потолка запросов —
в `config/crawler.php`, новая секция `okpd2`); (2) обход `children.html` от корня вширь с
соблюдением потолка запросов и вежливостной паузы; достигнут потолок — обход прекращается, остаток
помечается «не обойдено» и это ВИДНО в отчёте; (3) канал к площадке — через существующие сеймы:
`ProxyResolver::resolve(ProxyScope::CrawlListing, host)`, `PoliteThrottle`, `SourceTlsTrust`;
(4) сверка снятого с `prc_okpd2_nodes`: три класса расхождений — новый узел, исчезнувший узел,
узел со СМЕНИВШИМСЯ `external_id`; (5) запись: `--dry-run` только отчитывается, обычный прогон
делает `updateOrCreate` и проставляет `synced_at`; исчезнувшие узлы НЕ удаляются молча (см.
Implementation Rules п. 4); (6) код возврата: ненулевой, если хотя бы один изменившийся или
исчезнувший код используется профилем с `is_active = true`; (7) тесты по фикстуре ответа
`children.html` (`Http::fake()`): обход собирает узлы; смена `external_id` у кода активного
профиля даёт ненулевой код возврата; `--dry-run` не пишет в таблицу; потолок запросов соблюдается.
**Scope Excluded:** живые запросы из тестов (ни одного, `Http::fake()` обязателен); расписание
прогона команды — сводится с бюджетом тиков в P4/P5; обход всего справочника до листьев (потолок
запросов — сознательное ограничение); автоматическое удаление исчезнувших узлов; уведомления об
обнаруженном дрейфе (событие/письмо) — контур уведомлений строит P5; правка формы, фильтра,
билдера.

**Implementation Rules:** 1) Второго канала к площадке не появляется: только
`ProxyResolver` + `PoliteThrottle` + `SourceTlsTrust`. Голый `Http::get()` без этих трёх —
блокирующий дефект, а не стилистика: это ровно то поведение, ради предотвращения которого
существует P4 (гэп G7). 2) `verify => false` ЗАПРЕЩЁН — послабление `ignoreHTTPSErrors` живёт
только в launcher-е разведки (D10), боевой клиент ходит с бандлом по карте `crawler.tls.bundles`
(D125 плана `2026.07.31-SYS-INTEGRITY`, закреплено тестом). 3) Потолок запросов — жёсткий:
достигнут — обход ОСТАНАВЛИВАЕТСЯ, а не «докручивается быстренько»; остаток честно помечается
в отчёте и в коде возврата не участвует. 4) Исчезнувший узел НЕ удаляется из таблицы: он
помечается (например `synced_at` не обновлён + отчёт), потому что «узел не пришёл» и «узел удалён
на площадке» — разные события, а различить их одним прогоном нельзя. Удаление — операторское
решение. 5) Дрейф считается по паре (код, `external_id`): один и тот же код с другим id —
ИЗМЕНЕНИЕ, и если код используется активным профилем, это ненулевой код возврата. 6) Отчёт
команды называет числа с их источником: сколько запросов сделано, сколько узлов снято, сколько
новых/исчезнувших/изменившихся. 7) Ни один тест не ходит в сеть: `Http::fake()` + фикстура ответа
обязательны.
**Code Guidance:** Команда — тонкая (разбор опций, вызов сервиса, печать отчёта, код возврата);
обход и сверка — в `Okpd2NodeSynchronizer`; запись — в store-репозиторий (read/store split —
skill `repositories`). Классы `final`, `declare(strict_types=1)`, конструкторная инъекция,
именованные аргументы. Тесты — только `test('<интент по-русски>', fn)`; фикстура ответа снимается
из уже снятого артефакта либо конструируется минимально и честно помечается как синтетическая в
докблоке теста. **Запрещённые shortcuts:** `Http::get()` мимо прокси/паузы/TLS-бандла; `sleep()`
вместо `PoliteThrottle`; рекурсивный обход без счётчика запросов; «мягкий» режим, в котором дрейф
у активного профиля даёт нулевой код возврата; удаление узлов при первом же несовпадении.
