## Решение

**P9 исполняется item-за-item; workflow-скрипт не заводится, батч ровно один — `B2` (P9.6 + P9.7).** Критерий обязательной оркестрации (`plan-protocol` §7) проверен построчно и НЕ срабатывает: (а) независимы между собой РОВНО ДВА item'а — меньше требуемых трёх, остальные связаны по данным (карта → гейт → слияние → роспуск → роспуск → диаграммы → навигация); (б) длинной автономной цепочки без вмешательства владельца нет — удаление 1739 строк спек ровно то место, где результат смотрят

## Почему

Критерий бинарен: ни один сигнал не сработал → workflow не заводится «на всякий случай». Пара P9.6/P9.7 при этом проходит критерий СЛИЯНИЯ В БАТЧ (нулевая связность, один тир, один `Exec`, одна глубина ревью) — это разные механизмы, и батч оркестрацией не является. `RAG:— (repo-grounded: research/10-p9-docs-design.md §6)`
