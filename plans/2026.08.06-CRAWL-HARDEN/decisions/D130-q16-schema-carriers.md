## Решение

**Q16 закрыт: ни одно из 55 уникальных полей инвентаря без надёжного носителя не получает новую
колонку; все они остаются в `prc_procurements.attributes` (jsonb). Уже существующая
`prc_documents.kind` должна заполняться найденной категорией документа, но новая колонка для неё
не создаётся.**

## Почему

Владелец 2026-08-08 утвердил матрицу P8.1. Для каждого из 55 кандидатов не сработал ни один из
трёх признаков D83: по полю не фильтруют/не сортируют, обязательность у всех шести видов процедур
не подтверждена, в доменном правиле поле не участвует. Все 57 строк исходного инвентаря с
рекомендацией «колонка» уже имеют колонку; единственный незаполненный существующий носитель —
`prc_documents.kind`. **Consequences:** P8.2 не добавляет колонок по Q16; его schema-diff ограничен
поглощением уже существующих догоняющих миграций и сносом D82. Источник полной матрицы —
`findings/P8-schema-revision.md` §6 и `artifacts/eis-card-inventory.json`.
