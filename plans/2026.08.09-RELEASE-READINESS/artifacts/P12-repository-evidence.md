# P12 repository evidence template

`TEMPLATE — NO RUNTIME EVIDENCE.` P12.2 validates this schema locally. A separate operator
rehearsal plan fills only redacted public-key fingerprints, GitHub host-key source/date,
repository origins, exact Agelto/AzGuard SHAs, clean status, read-only auth result and
rotation/revocation receipt. Empty fields are not a current-plan deviation or production proof.
