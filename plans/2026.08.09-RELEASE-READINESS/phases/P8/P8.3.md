**Intent:** Эволюционировать `prc_status_mappings` по D36: ровно platform-default или exact-registry applicability, existing rows без semantic change, детерминированная precedence и DB-enforced uniqueness. RAG:— (repo-grounded: D36 and `research/10-P8-execution-design.md`).

**Implementation Rules:** Migration table/FKs use model `getTable()`. Constraint enforces exactly one non-null FK; partial uniques are `(platform_id, source_stage) WHERE platform_id IS NOT NULL` and `(registry_id, source_stage) WHERE registry_id IS NOT NULL`. Existing rows keep registry IDs. `down()` inspects platform-scope rows and refuses before any DDL if lossless restoration is impossible; it never deletes/collapses data. Scope enum is derived from validated columns, not a second persisted truth. RAG:— (repo-grounded: D36 and php:database conventions).
**Code Guidance:** Сначала red migration tests on current schema, затем expand/backfill/constraint/index; не переписывать create migration и не raw-hardcode table names. If current PostgreSQL/Laravel cannot express reversible DDL safely — STOP plan-design, no silent data-dropping `down()`.
