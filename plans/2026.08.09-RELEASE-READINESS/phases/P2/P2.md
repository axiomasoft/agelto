# P2 — Local vendor, secrets, preflight, bootstrap и Laravel Doctor

## Phase Context

Фаза закрывает dependency/configuration/bootstrap boundary до application-readiness P3. Private
AzGuard остаётся отдельным nested checkout, но становится full-SHA-pinned и проверяемым входом
Composer/image build. Dev/prod secrets получают file-backed Compose carrier, create-only generator
и redaction/leakage gates. RAG:— (repo-grounded: `research/04-P2-execution-design.md`, D6/D19/D20).

P0.6 и P1.5 терминальны; P2.1–P2.6 исполнены, но RED-аудит выявил разрыв общего readiness
contract. P2.7 адресно исправляет F1–F8 по D70; D19–D21 и чужие фазовые contracts не
перепроектируются. RAG:— (repo-grounded: terminal state carriers, P2 audit, D70).

> **Контракт фазы (contract-first).** Потребляет: terminal P0.6/P1.5, `root/contracts/release-readiness-v1.md`, D6/D9/D17–D21, P2 repo/RAG findings и current vendor/env/seeder/Doctor carriers · Производит: pinned local vendor closure, file-secret contract, non-mutating preflight, resumable bootstrap, base/demo/admin commands и one-off Doctor profile · Границы: P3 владеет Livewire/Filament assets/final app readiness, P11 — CI integration, P12 — Ubuntu provisioning/deploy/rollback/clean-room rehearsal

## Scope Included

1. Tracked `local/vendors` boundary, full-SHA vendor manifest, sync/check и Composer/image closure.
2. Create-only env/file-secret generation, service-scoped Compose mounts, permissions и leakage tests.
3. Read-only host/repo/env/port/Compose preflight с deterministic agent output.
4. Idempotent staged bootstrap для dev и production-image build без destructive cleanup.
5. Production base seeders, local demo data и secret-safe initial-admin create/reset commands.
6. First-party Laravel Doctor local/production profiles, custom diagnostics и companion image.
7. Final audit remediation: обязательные real carriers, fail-closed diagnostics/security boundaries и append-only evidence reconcile.

## Scope Excluded

- Livewire versioned asset 404, Filament publish/manifest и final `/admin` interaction — P3.
- CI pipeline/parallel tests — P11; Ubuntu, SSH/deploy keys, registry, DNS/TLS, rollback/backup rehearsal — P12.
- Secret values в Git/env/image/log/argv, automatic credential rotation, floating vendor refs или destructive DB/volume operations.
- Изменение private AzGuard source/reference tree и исправление доменной application logic.

`app/Doctor/Diagnostics/BaseDataIsReady.php:19`, `phases/P2/P2.6.md:10`**

цикл по четырём ключам, но фактически проверяет только тип `config('app.key')`; DB/Redis/AWS ветки
