### P2.3 — Сделать fail-closed host/repository/env/Compose preflight

**Intent:** Реализовать один read-only preflight с human/agent output, который до build/up доказывает host tools, private vendor, env/secrets, ports, permissions и standalone Compose contracts без утечки значений. RAG:— (repo-grounded: D19/D20 and P1 command contract).
**Why:** Разрозненные Make guards проверяют лишь наличие env files и могут перейти к mutation при неверном vendor ref, placeholder secret, занятом порте или невалидном production config. RAG:— (repo-grounded: current `docker/Makefile`).
**Scope Included:** Host/version/daemon checks · repo/vendor origin/SHA/dirty checks · env key/schema/placeholder checks · secret permission/service-grant checks · port/storage checks · quiet Compose render · stable exit codes and agent JSON · fake-tool/non-mutation contract tests · docs.
**Scope Excluded:** Установка host tools · clone/fetch · secret generation/rotation · build/pull/up/down · migrate/seed/admin · network reachability beyond local Docker daemon.
**Inputs:** `research/04-P2-execution-design.md` · `phases/P1/P1.5.state.md` · `phases/P2/P2.2.state.md` · D19 · D20 · `docker/Makefile`
**Files:** `docker/scripts/preflight.sh` · `docker/tests/preflight-contract.sh` · `docker/Makefile` · `docs/03_Dev/commands.md` · `docs/03_Dev/getting-started.md` · `docs/03_Dev/docker/troubleshooting.md`
**Required Reads:** 1) `plans/2026.08.09-RELEASE-READINESS/research/04-P2-execution-design.md` 2) `plans/2026.08.09-RELEASE-READINESS/phases/P2/P2.2.state.md` 3) `D19` 4) `D20` 5) `docker/Makefile` 6) `composer.json` 7) `./.env.example` 8) `./.env.docker.example` 9) `./.env.docker.production.example` 10) `docker-compose.yml` 11) `docker-compose.prod.yml`
**Implementation Rules:** P2.2 terminal is a hard gate. Preflight has explicit `MODE=dev|prod-build|prod-runtime` profiles and stable check IDs/severity/exit summary; unknown mode fails. It reads P1 version thresholds rather than duplicating them. Compose uses `config --quiet` or redacted structured inspection, never dumps resolved values. Before/after Docker state fingerprints must match. Missing vendor pin, dirty package source, symlinked/weak secret file, placeholder/duplicate key, occupied required port or missing service grant is fatal. RAG:— (repo-grounded: D19/D20 and plan Execution Rules).
**Code Guidance:** Reuse P1 fake-Docker harness and P2 vendor/secret helpers; no `eval`, unquoted expansion, `source .env`, `docker compose up`, `|| true` on required checks or secret values in messages. JSON output contains check ID/status/remediation only. Анти-самообман: a check that cannot prove non-mutation carries a before/after assertion; skipped mandatory tool/config is failure, not warn.
**Validation:** `bash -n docker/scripts/preflight.sh docker/tests/preflight-contract.sh` · `bash docker/tests/preflight-contract.sh` covers each fatal class, redaction and exact exit codes · fake Docker log proves only version/info/config/inspect/ps-class reads and no build/pull/create/start/stop/remove · real `make infra:preflight MODE=dev` and `MODE=prod-build` green on validation fixtures with identical container, image and volume fingerprints before/after · agent mode parses as one JSON line with no sentinel · `git diff --check` green.
**Deliverables:** Unified non-mutating preflight, stable human/agent report contract, exhaustive failure fixtures, Make target integration and troubleshooting docs; separate item commit.
