**Intent:** На проверенном P12.1 host создать двухрепозиторный read-only Git SSH carrier и получить clean exact Agelto checkout плюс D19-pinned AzGuard checkout в `local/vendors` без токенов, agent forwarding или слепого trust-on-first-use. RAG:✅ 2026-08-09 GitHub deploy-key/fingerprint docs in P12 finding; D19/D43.

**Implementation Rules:** P12.1/P2.1 terminal. Generate distinct named keys only when absent; never overwrite a key. Each SSH alias uses `IdentitiesOnly yes`, its own `IdentityFile`, pinned GitHub host key and read-only repository access. Current official GitHub fingerprint is operator-verified before `known_hosts` write. Clone paths, normalized origins, candidate SHA and D19 private SHA are profile/lock inputs; update refuses dirty/untracked package paths, wrong origin, non-full SHA or non-fast-forward branch ambiguity and never reset/clean. Agelto checkout must be detached/exact candidate; AzGuard lives only under ignored `local/vendors/azguard` and passes existing vendor contract.
