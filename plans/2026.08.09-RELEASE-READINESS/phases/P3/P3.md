## Scope Included

1. Runtime repro с admin HTML, hashed Livewire URL, route inventory, Nginx config/log evidence.
2. Nginx fallthrough, Filament asset sync/check/repair и immutable image/deploy integration.
3. `/up` liveness boundary, active DB/cache/storage/assets/worker readiness и Doctor delegation.
4. Exact Playwright Test/Chromium setup, ignored auth state и isolated candidate-tree clean install.
5. Bootstrap/assets/cache/restart two-run idempotency и узкое восстановление удалённого asset.

## Scope Excluded

- Private documentation storage/authorization — P4; full Filament navigation/forms/tables localization — P9.
- CI sharding/cache/full risk-based E2E — P11; Ubuntu provisioning, registry/TLS/rollback/final rehearsal — P12.
- Domain pipeline behavior, production data reset, volume deletion, credential rotation или broad dependency upgrade.
- Вывод root cause без P3.1 evidence либо принятие public Livewire copy как второго SSOT без superseding D22.
