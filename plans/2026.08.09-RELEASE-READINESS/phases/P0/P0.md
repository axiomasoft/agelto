# P0 — Разведка репозитория, референсов и RAG-контракты

## Phase Context

Фаза сначала материализует общий исполняемый citation gate, затем снимает воспроизводимый baseline Agelto и трёх локальных reference projects и проверяет внешние практики по первичным источникам. Product code и чужие репозитории остаются read-only. Выходы — project-level citation verifier, findings, сравнительная матрица, проверенные RAG-вердикты, alternatives и единый замороженный contract для P1–P12. RAG:— (repo-grounded: D48, `research/01-P0-execution-design.md`).

> **Контракт фазы (contract-first).** Потребляет: `brief/00-brief.md`, `brief/01-refinements.md`, `findings/bootstrap-recon-2026-08-09.md`, `findings/P0-reference-input-map-2026-08-09.md`, текущее дерево Agelto и read-only Sova/Vintera/Dterema · Производит: `plans/verify-citations.py`, P0 findings, source/snapshot evidence, gap/coupling matrix, `root/contracts/release-readiness-v1.md`, D-records и route-review matrix для P1–P12 · Границы: кроме project-level citation carrier не правит application, Docker, Composer, schema, project docs и reference repositories; skeleton routes будущих фаз меняются только в их собственном plan-design.

## Scope Included

1. Исполняемый stdlib citation verifier с embedded selftest и fail-closed strict mode до P0.1.
2. Инвентарь Agelto по восьми несущим поверхностям: Docker/Make, deploy/bootstrap, secrets, assets/readiness, protected docs, proxy, document/extension pipeline, tests/CI.
3. Сравнение Sova, Vintera/CMS и Dterema по одной матрице с полным snapshot provenance для dirty trees.
4. Три RAG-трека по инфраструктуре, Laravel-экосистеме и domain/security contracts с independent verification.
5. Синтез alternatives, acceptance matrix, consumer map, frozen contract и route-review matrix.
6. Отдельный fresh-context phase audit после закрытия P0; неудачная попытка workflow-авторинга сохранена как evidence D15.

## Scope Excluded

- Любые правки application code, Docker/Compose/Makefile, Composer, env, schema, tests и project docs.
- Копирование reference repositories в Agelto, их checkout/stash/commit или очистка dirty state.
- Выбор новых dependencies без официального source/compatibility verdict; implementation любого из выбранных contracts.
- Самовольное закрытие owner-policy развилки: необратимая или равносильная альтернатива остаётся proposed decision.

## Sequence and orchestration

| Шаг | Зависимость | Носитель |
|:--|:--|:--|
| P0.0 | audit F1 + frozen D48 CLI contract | `task:plan-exec` |
| P0.1 | terminal P0.0 + исходный repo baseline | manual `task:plan-run` |
| P0.2 | схема инвентаря P0.1 | manual `task:plan-run` |
| P0.3 | пробелы P0.1/P0.2 | manual `task:plan-run` |
| P0.4 | P0.3 runtime/deploy вердикты | manual `task:plan-run` |
| P0.5 | P0.4 stack/security вердикты | manual `task:plan-run` |
| P0.6 | все findings P0.1–P0.5 | frontier `task:plan-run` → bounded self-audit; после close — fresh-context `task:plan-audit P0` |

Оркестрация не заявлена. P0.0→P0.1 и P0.3→P0.4→P0.5 — последовательные цепи: downstream item потребляет terminal state или findings предыдущего, поэтому три независимых scope нет. Цепь не предназначена для одного autonomous run: citation carrier закрывается отдельно, а каждый findings-коммит замораживает query inputs следующего item. D15 отклонил workflow fallback после RED статического гейта. RAG:— (repo-grounded: D48, `findings/P0-workflow-static-review-2026-08-09.md`, D15).

## External fact classes

- Tool/runtime versions, Docker/Compose/image/secret/readiness practices and provider constraints use primary official sources captured by P0.3/P0.4.
- Laravel/Filament/Livewire/Spatie/Pest/package compatibility and supported APIs use locked-source plus official documentation captured by P0.4/P0.5.
- Domain/security contracts for private docs, proxy, archives, extraction and deployment are verified by P0.5 against primary specifications; unverifiable claims stay `[UNVERIFIED]` and cannot enter P0.6 freeze.
