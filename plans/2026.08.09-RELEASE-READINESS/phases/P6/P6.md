## Phase Context

Фаза hardens существующий download→prepare contour вместо второго document pipeline. Один typed
registry сопоставляет normalized extension, detected MIME и format-specific signature с ровно одним
handler; unknown/mismatch становятся terminal с отдельной enum-причиной. Архивы проходят bounded
entry processing, а не blind bulk extraction. RAG:— (repo-grounded:
`findings/P6-format-archive-recon-2026-08-09.md`, D30/D31).

P6.1 сверил terminal P0.5/P0.6 evidence и оставил D30/D31 неизменными; P6.2–P6.6 исполнили
registry→bounded extraction→child lifecycle→integration→extension-gate цепочку. Audit P6, заход 1,
доказал bounded GSFX/evidence seam и переоткрыл фазу одним P6.7; semantic document taxonomy/
summary/tags остаются P7. RAG:— (repo-grounded: `research/08-P6-execution-design.md`,
`research/22-P6-audit-remediation.md`, Audit P6 2026-08-12).

> **Контракт фазы (contract-first).** Потребляет: terminal P0.5/P0.6, `root/contracts/release-readiness-v1.md`, D5/D30/D31/D77, current Document/DocumentVersion/storage/job/prepare invariants, representative corpus and Audit P6 round 1 · Производит: frozen format evidence matrix, typed registry/result/reasons, bounded ZIP/7z/RAR/GSFX-attachment processing, unique parent-child lineage, after-commit ordinary dispatch, adversarial integration/typed-suite proof, truthful closure evidence and extension contract docs · Границы: не определяет semantic document taxonomy/summary/tags P7, не создаёт второй pipeline/storage carrier, не ослабляет FileLocationResolver/test DB/media guards, не переписывает historical evidence, P10 владеет cross-cutting audit, P12 — production rehearsal

## Scope Included

1. Reconcile terminal P0 format/archive findings and freeze extension/MIME/signature/handler matrix.
2. Typed format registry/inspector/result plus durable machine-readable unprocessable reason.
3. Safe bounded archive metadata/path/type/resource validation and per-entry extraction.
4. DB-enforced child lineage, content-addressed storage, terminal parent outcome and after-commit jobs.
5. Real archive→children→ordinary processing and adversarial retry/concurrency/security proof.
6. Auto-failing new-handler contract, developer/operator documentation and architecture guard.
7. One bounded P6.7 remediation for Audit P6 F1–F5, followed by independent Audit P6 round 2.

## Scope Excluded

- Semantic `Document.kind` taxonomy, summaries, estimates/tags or Filament information architecture.
- Executable/script/media formats not named by the owner; antivirus/CDR service adoption.
- A second document/file table, storage resolver, queue pipeline or generic plugin framework.
- Silent best-effort extraction, partial child sets, catch-all passthrough or direct object paths from entry names.
- Cross-cutting security audit P10, CI topology P11 and clean Ubuntu production rehearsal P12.
