## Scope Included

1. Канон Make targets и non-mutating help/preflight для developer/operator/agent.
2. Dev source bind mount, project-scoped runtime volumes/names, health dependencies и non-TTY agent execution.
3. Immutable production Compose/image contract, non-root runtime и BuildKit cache boundaries.
4. Pinned pnpm lock, отдельный Vite dev service, constrained HMR/CORS и production frontend stage.
5. Классификация code/php-deps/frontend/runtime/image-promotion, executable contract tests и docs sync.

## Scope Excluded

- Private Composer repository transport, `auth.json`, secret generation/runtime secret policy и full vendor closure — P2.
- Livewire/Filament publish/manifest diagnosis и final application readiness — P3.
- CI workflow implementation и Pest 5 tuning — P11; clean Ubuntu/prod deploy/rollback/backup rehearsal — P12.
- Любая destructive DB/volume operation, application/domain code или изменение reference repositories.
