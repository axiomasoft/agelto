# naming-canon — карта переименований и канон имён AI-контура

**Контракт P1.1 плана `2026.07.28-EST-ARCH`.** Замораживается утверждением владельца (строка
в `plan.md` → `## 6. Update Log`). После заморозки правится ТОЛЬКО новой D-записью со ссылкой
`supersedes` — правка «по ходу» исполнения любой фазы запрещена (`plan-protocol` §11).

**Якорь фактов:** все числа и перечни получены на `143002b` командами, названными в колонке
«Почему» либо в разделе «Как воспроизведён инвентарь» ниже.

**Правило чтения колонок.** «Сейчас» — имя в репозитории на якоре. «Целевое» — имя после
исполнения. «Класс правки» — что физически меняется. «Фаза-исполнитель» — item, который обязан
эту строку исполнить; строка без исполнителя = дыра. «Почему» — критерий выбора имени;
по умолчанию действует критерий **минимальной поверхности правки при одинаковом результате**,
обратный ход требует аргумента сильнее.
