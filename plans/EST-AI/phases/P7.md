**Scope Excluded:** shadow-режим и CI-гейт (Фаза 6 роадмапа целиком — после появления реального голдена); ANLS-метрики.
**Inputs:** схема dataset_examples/eval_* — research/D §Схема; метрики — ТЗ 04 §5.
**Files:** app/Console/Commands/Ai/{DatasetImportCommand,EvalRunCommand}.php · app/Services/Procurement/Extraction/EvalMetrics.php · docs/specs/v2/08-estimate-extraction.md (раздел формата папки) · tests/Feature/Ai/{DatasetImportTest,EvalMetricsTest}.php

### P7.6 — Деплой с живыми очередями: graceful, холодный режим

**Status:** ⬜ Not started
**Intent:** Канон D26 в коде и конфиге: (1) docker-compose.prod.yml — `stop_grace_period` у horizon-сервиса (config-значение, default 900s — больше самого длинного job) + проверка инварианта `job timeout < horizon supervisor timeout < queue.retry_after`; (2) Makefile-цель `prod:deploy` — последовательность: pull → (флаг `COLD=1` → `horizon:pause`) → `migrate --force` (one-off контейнер, только аддитивные — правило в комментарии цели) → `horizon:terminate` → `up -d` → `horizon:status` (+ `horizon:continue` при COLD); (3) длинные консольные команды пайплайна (retry-failed, stuck-check — короткие; если появился демон-режим) — `Isolatable`; шаблон SIGTERM-обработчика (SignalableCommandInterface: доработать текущую единицу → exit 0) — как трейт/базовый класс для будущих демонов; (4) runbook-заготовка деплоя (docs/03_Dev/process/deploy.md наполняется в P10.3 — здесь черновик в docs/specs/v2/08 §эксплуатация или комментарии Makefile).

**Scope Included:** compose/horizon/queue-конфиги, Makefile-цель, Isolatable/SIGTERM-шаблон, smoke-тест инварианта таймаутов (юнит: сравнение config-значений).

**Inputs:** plans/EST-AI/research/J-infra-ops.md §2,§4 (семантика horizon:terminate = SIGTERM+queue:restart-флаг; horizon:pause/continue официальны; maintenance mode останавливает и очереди — для паузы пайплайна использовать pause, не down; stopWaitingSeconds не существует).
**Files:** docker-compose.prod.yml · config/horizon.php · config/queue.php · Makefile · app/Console/Concerns/GracefullyStoppable.php (трейт) · tests/Unit/Config/QueueTimeoutInvariantTest.php
**Required Reads:** 1) plans/EST-AI/research/J-infra-ops.md §2,§4 2) docker-compose.prod.yml · Makefile (текущие) 3) config/horizon.php (P4.1) 4) docs/specs/v2/06-roadmap.md Фаза 0 (docker-канон)
