# P8 — Промт-система: сиды, protected, базовые тексты

## Phase Context

Реализует D5+D17: промты — файлы `resources/ai/prompts/**` под git (источник истины), в БД `prc_ai_prompts` их доставляет `PromptSeeder` через обычный `php artisan db:seed` (upsert по кодовому полю `key` + `version`, id не используется). Сидовые промты защищены флагом `is_protected` — из админки они read-only, операторы могут только создавать дополнительные корректирующие записи (не-protected). Базовые тексты закладываются здесь: слоёная структура по шагам (global → step-global → step, канон композиции P3.3) — несколько промтов, постепенно раскрывающих шаги парсинга, а не один монолит. Это точка входа следующего шага владельца: другая модель будет итерировать тексты по папке эталонных смет с обратной связью через `ai:eval:run` (P7.4). Фаза завершена: `migrate:fresh --seed` даёт рабочий набор промтов, protected-поведение под тестами.

### P8.1 — Файловые промты: структура, сидер, базовые тексты

**Status:** ⬜ Not started
**Intent:** МИГРАЦИЯ ПЕРВОЙ: колонка `is_protected` (boolean, default false) на `prc_ai_prompts` — правка миграции 100029, пока данных нет (ревью K п.1: сидер пишет это поле — колонка обязана существовать до seed). Затем структура `resources/ai/prompts/<step>/<priority>-<key>.md` (front-matter: key/step/version/priority/is_active) + `PromptSeeder` (читает файлы, upsert в `prc_ai_prompts` по `(key, version)`, ставит `is_protected=true`; вызывается из DatabaseSeeder — деплой промтов = `php artisan db:seed`) + artisan `ai:prompts:sync --check` (CI-сверка дрейфа файлы↔БД) + базовый комплект текстов для ВСЕХ 8 значений enum PromptStep (D37): global (только JSON, «нечитаемое → null», числа без пробелов), screening:global (общие правила классификации), screening:classify (типы, признаки сметы, ignore_reason), extraction:global (роль «система извлечения данных из строительных смет РФ», нормативные базы ГЭСН/ФЕР/ТЕР/ФССЦпг/ТСН/БД), extraction:discovery (маркеры границ смет для оконного пути — «на этих страницах: начало новой сметы / конец / продолжение предыдущей; title если виден», дёшево, D30/D37), extraction:passport / extraction:rows (правила буфера incomplete_items!) / extraction:totals (НР/СП/НДС, рекурсия «в том числе»). **Scope Excluded:** тюнинг качества текстов (следующий шаг владельца); protected-поведение админки (P8.2); корректирующие hints обучающего контура (P9.1 — это ДРУГАЯ сущность, не prc_ai_prompts).
