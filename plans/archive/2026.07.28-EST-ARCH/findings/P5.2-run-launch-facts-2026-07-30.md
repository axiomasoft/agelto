## 4. Повторный прогон той же версии сегодня НЕ проходит

- `WorkingCopyProvisioner::provision()` идемпотентен по содержимому: документ резолвится по
  `external_id = "fixture:{$fixture->code}"`, версия — по `sha256`
  (`findVersionByHash`) → повторный запуск того же эталона даёт ТУ ЖЕ `DocumentVersion`.
- `app/Repositories/Procurement/AnalysisStoreRepository.php:34-52` — `firstOrCreate()` возвращает
  АКТИВНЫЙ (`->active()`, т.е. `superseded_at IS NULL`) анализ пары «версия + шаг», если он есть;
  новый создаётся только при его отсутствии, и только тогда резолвится активный прогон
  (`:63-73`, `NoActiveAnalysisRun` при отсутствии).
- `app/Jobs/Procurement/ScreeningJob.php:59-81` — guard пропускает работу только если активного
  анализа скрининга нет ЛИБО он `pending`/`running`; терминальный активный анализ прошлого прогона
  делает передиспатч no-op.
- Следствие: без снятия активных анализов версии второй прогон эталона не сделает ни одного
  LLM-вызова, а его анализы (если бы создались) остались бы привязаны к ПЕРВОМУ прогону
  (`analysis_run_id` пишется при создании и не обновляется — §3.5 контракта).
