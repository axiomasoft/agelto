# plt_prompt_rules — источник недоступен/пуст

**Проверено:** 2026-07-08

Проверены оба кандидата на живой источник `plt_prompt_rules`:

1. **Docker volume `agelto_pgsql_data`** (единственный не-v2 Postgres-volume в окружении) — поднят
   временно (read-only разведка, без изменений) под `docker compose` из `Old/`, project name
   `agelto`. В БД `agelto` применены только 6 базовых миграций Laravel
   (`users/cache/jobs/media_library/geo_countries` + jobs/cache) — таблицы `plt_prompt_rules`,
   `Prompt`-модуля и вообще estimate/document-функционала НЕТ. Это снэпшот состояния ДО появления
   промт-подсистемы.
2. **`Old/database/database.sqlite`** — не проверялся по прямому решению владельца (см. ниже):
   разработка v2 идёт фактически с нуля, боевых/тестовых данных в БД нет, восстанавливать
   исторические тексты промтов из гипотетических дампов не требуется.

**Решение владельца (2026-07-08):** живых данных `plt_prompt_rules` нет и не нужны — план
переопределяет уже реализованное; проект стартует по факту заново. Единственный сохранившийся
текстовый источник промтов v1 — `Old/docs/03_Dev/LLM_Strategy.md` §10 (уже выжат в
`plans/archive/2026.07.07-EST-AI/research/B-old-prompts.md` §«Тексты промтов»); PHP-схемы/словари `#[Alias]` — в
`Old/app/Process/EstimateAnalysis/Schema/**`. Оба источника переносятся в спеку `08-estimate-extraction.md`
силами item P1.2, реальным наполнением боевых промт-текстов займётся отдельный шаг владельца
(P8, per plan.md §1 «Следующий шаг владельца»).

**Вывод:** база `plt_prompt_rules` не переносится и не восстанавливается — считается пустой/недоступной.
Item закрыт без эскалации по прямому решению владельца.
