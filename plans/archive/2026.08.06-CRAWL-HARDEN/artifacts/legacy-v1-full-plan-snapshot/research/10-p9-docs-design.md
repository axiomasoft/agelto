## 4. Гейт целостности: форма и порядок

**Форма** — unit-тест на `Symfony\Component\Finder`, идиома уже в дереве
(`tests/Unit/Architecture/DomainLayoutTest.php`): предмет проверки — путь и строка, БД не нужна.
Адрес — `tests/Unit/Docs/DocsIntegrityTest.php`. Три свойства:

1. **frontmatter** — у каждого `docs/**/*.md` есть блок `---`, в нём `audience:` из
   {dev, operator, owner, shared} и `type:` из {howto, reference, explanation, runbook, adr};
   у `04_Operators/how-to/**` дополнительно `last-reviewed:` формата даты.
2. **ссылки** — каждая относительная markdown-ссылка резолвится в существующий файл
   (якорь `#...` отбрасывается; внешние `http(s)`/`mailto:` пропускаются).
3. **сироты** — каждый файл достижим из `docs/index.md` по цепочке ссылок через `_index.md`
   разделов. Свойство включается ПОЗЖЕ остальных (см. ниже).

**Самоочищающийся список исключений.** Гейт заводится ДО переносов (это его единственная
осмысленная позиция: он страхует именно перенос ~1900 строк, Ф-6), но на момент заведения в дереве
18 файлов без frontmatter, 17 из которых будут удалены двумя следующими items. Проставлять
`status: living` файлу, который через два item'а исчезнет, — записать в дерево ложь. Поэтому тест
несёт ЯВНЫЙ список исключений с адресом item'а-ликвидатора у каждой строки:

```php
// Снимается P9.3 (слияние docs-private).
'docs-private',
// Снимается P9.4 (роспуск 00–07) и P9.5 (роспуск 08).
'docs/specs/v2',
```

Каждый следующий item УДАЛЯЕТ свою строку исключения, а P9.8 доказывает, что список пуст, и
включает свойство 3 (до сборки навигации «сирот» ловить бессмысленно — навигации ещё нет).
Гейт, который нельзя выключить точечно, был бы либо красным всю фазу, либо всеядным; список с
адресатом у каждой строки — единственная форма, которая заканчивается сама.

## 7. Ловушки фазы

**Л-1. Транскрипция превращается в копирование.** Соблазн перенести спеку целиком «чтобы не
потерять». Признак: раздел `03_Dev` вырос на 300 строк и содержит критерии приёмки фаз 2026 года.
Правило отбора — §3.2; всё, что не проходит, либо не переносится, либо выписывается в Pending Work.

**Л-2. Ссылка переведена не туда.** `08-estimate-extraction.md` цитируется по ПАРАГРАФАМ
(`§7`, `§3.2`, `§4в/§4г`). Перенос без сохранения нумерации разделов делает эти ссылки формально
живыми, а фактически ложными. Правило: новый канон сохраняет НОМЕРА разделов источника либо
ссылка переписывается на новый номер — по факту, а не «примерно».

**Л-3. Гейт зеленеет на пустоте.** Тест, который не нашёл ни одного файла (опечатка в пути
Finder'а), проходит. Обязателен контрольный счётчик: тест утверждает, что просмотрено ≥N файлов и
≥M ссылок, числа — из замера item'а, а не из головы.

**Л-4. Файл удалён, а ссылка на него — в архивном плане.** Архивы append-only (прецедент D87):
ссылки в `plans/archive/**` НЕ правятся и в скоуп не входят. В скоупе — `CLAUDE.md`,
