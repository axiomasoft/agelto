### P4.3 — Реализовать manifest-backed locator и единый secure controller

**Intent:** Выдавать только verified manifest entries одним Laravel route/controller с одинаковыми path, MIME, cache и browser-security правилами для HTML и каждого asset. RAG:✅ 2026-08-09 Laravel 13 file responses, RFC 9111 and OWASP traversal/headers; D27.
**Why:** Extension-based auth bypass и substring `..` check Vintera не закрывают encoded/backslash/symlink traversal; public/static fallback превращает assets в отдельную незапертую систему. RAG:— (repo-grounded: P4 finding and Vintera SHA evidence).
**Scope Included:** Typed/configured private artifact root · immutable manifest reader/value · safe request-path resolver · manifest membership + `realpath` containment · closed MIME · HTTP-only invokable controller · one GET/HEAD wildcard route · root/nested/static/missing responses · `private,no-store`, nosniff, no-referrer, same-origin resource policy and tested HTML CSP · focused unit/feature tests · docs.
**Scope Excluded:** Role/permission catalog/navigation P4.4 · public/Nginx/X-Accel/signed URLs · directory listing · dynamic Markdown rendering · uploads · caching/ETag/conditional public response · arbitrary configured absolute roots in production.
**Inputs:** `phases/P4/P4.2.state.md` · `research/06-P4-execution-design.md` · D26 · D27
**Files:** `config/documentation.php` (new) · `app/Services/Documentation/PrivateDocumentationLocator.php` (new) · `app/Services/Documentation/PrivateDocumentationAsset.php` (new) · `app/Http/Controllers/Documentation/PrivateDocumentationController.php` (new) · `routes/web.php` · `tests/Unit/Documentation/PrivateDocumentationLocatorTest.php` (new) · `tests/Feature/Documentation/PrivateDocumentationResponseTest.php` (new) · `docker/tests/private-documentation-response-contract.sh` (new) · `docs/03_Dev/private-documentation.md`

**Implementation Rules:** P4.2 terminal. Locator, not controller, owns manifest/path/MIME; controller only authorize hook placeholder→locate→`response()->file()` headers. Requested path must be exact manifest member after known-good ASCII grammar; reject `%`, backslash, NUL and empty/dot/dot-dot segments, then verify both root and file `realpath` containment. Missing build/manifest/file/unsafe path/unknown MIME returns the same 404 surface without leaking disk paths. Every 200 shares `Cache-Control: private, no-store`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Cross-Origin-Resource-Policy: same-origin`; HTML CSP must pass actual build. RAG:✅ 2026-08-09 RFC 9111/OWASP. No framework/storage disk URL or Nginx alias.
**Code Guidance:** Use `final readonly`, constructor injection and named arguments; no `Request` below controller, no mutation/DB/Action/Repository. Parse manifest strictly (schema, unique sorted paths, MIME allowlist), cache only request-locally, never trust extension/finfo over manifest. Никакого спец-кода под attack strings: one normalization/containment path handles every request. Анти-подгонка: if a traversal fixture reaches file I/O, fix the general resolver; do not blacklist that literal. Route may be registered only with a fail-closed authorization placeholder that P4.4 replaces/tests before phase close; an allow-all interim route is forbidden.
**Validation:** `bash docker/tests/private-documentation-response-contract.sh` — item-owned carrier first performs test-DB preflight, then runs the focused locator/response suite for root/nested/asset/missing/malformed-manifest/encoded+double-encoded/backslash/NUL/dot/symlink/outside-root corpus; it asserts exact body/MIME/security headers, 404 for unknown/missing files, one GET|HEAD docs route, only the declared `response()->file()` controller, Pint/PHPStan and `git diff --check`.
**Deliverables:** Strict manifest/asset value, path-safe locator, one response controller/route, closed MIME/security headers/CSP and adversarial focused tests; separate item commit.
