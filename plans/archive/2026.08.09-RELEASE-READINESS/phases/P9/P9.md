## Scope Included

1. Terminal-upstream reconcile and complete resource/page/route/schema/table/auth inventory.
2. Ordered Russian navigation, explicit resource/page labels and AzGuard source-package localization hook.
3. Context-safe enum labels and unambiguous boolean presentation without persistence changes.
4. Named operator-task Sections, purposeful helper text and unchanged validation/dehydration.
5. Responsive tables, hidden-by-default technical IDs, long-text/full-value and action contracts.
6. Runtime route/role matrix, focused Livewire tests, mobile/desktop Playwright sweep and docs sync.

## Scope Excluded

- Изменение domain model, migrations, status applicability, proxy semantics, prompt/schema contracts.
- Изменение resource slugs, permission keys, role grants, Policies/Gates или hidden-page reachability.
- Ручная правка `vendor/**`, custom navigation engine, custom CSS/JS table framework или второй E2E stack.
- Перевод внутренних code identifiers, логов, API payloads и технической документации ради UI.
- Общий security/code audit P10, Pest/CI redesign P11 и production deploy/rehearsal P12.
