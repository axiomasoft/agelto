### P8.2 — Запечатать минимальный contract добавления новой площадки

**Intent:** Реализовать запечатанный D35 minimal runtime contract: typed platform definition по точному `Platform.code`, единый registry lookup для source methods и registry filters, и перевести factory/form consumers без dual maps. RAG:— (repo-grounded: D35 and `research/10-P8-execution-design.md`).
**Why:** `Registry.code` уникален только внутри platform, а текущая global filter map collision-prone; transport-only `SourceMethod::Csv` ведёт к EIS-specific implementation и делает data-only onboarding claim ложным. RAG:— (repo-grounded: `findings/P8-platform-status-extension-recon-2026-08-09.md`).
**Scope Included:** Terminal P8.1 gate · typed immutable `PlatformAdapterDefinition` validating class-string maps · `PlatformAdapterRegistry` sole config reader · exact platform→source method and platform→registry filter resolution · eager platform/registry load contract · migrate SourceMethodFactory/CrawlerFilterFactory/CrawlerForm and all call sites · EIS definition · descriptive fail-closed exceptions · config-cache/static-analysis compatibility · focused synthetic collision tests.
**Scope Excluded:** New real platform/source method · changing EIS request/parser behavior · status schema/resolver P8.3/P8.4 · DB-stored FQCN · universal adapter interface with listing/detail/status methods · compatibility reads from old maps after cutover.

Validate every source method implements `Contracts\SourceMethod` and every filter is a Laravel Data class before return. Registry resolution requires loaded/resolveable platform and reports both codes. Missing platform/method/filter fails closed; no EIS/global fallback. Old `crawler.source_methods`/`crawler.filters` have zero runtime consumers after cutover. RAG:— (repo-grounded: D35 and existing fail-closed CrawlerFilterFactory contract).
