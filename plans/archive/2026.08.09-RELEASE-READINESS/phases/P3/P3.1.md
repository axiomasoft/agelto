> Runtime acceptance (2026-08-11): an isolated dependency-ready topology reaches `/admin/login`; its emitted `/vendor/livewire/livewire.js?id=…` returns `200 application/javascript`. Evidence: `findings/P3.1-livewire-runtime-evidence.md`.

**Intent:** Получить воспроизводимый before-fix trace admin HTML → exact Livewire asset URL → Nginx response/location → Laravel route/vendor file и доказать либо опровергнуть ведущую static-location гипотезу до mutation. RAG:— (repo-grounded: `findings/P3-livewire-readiness-recon-2026-08-09.md`).
**Why:** Наличие Composer hook или route в vendor не доказывает, почему browser получил 404; fix без layer-by-layer evidence может скрыть stale manifest, wrong APP_URL или proxy/cache defect. RAG:— (repo-grounded: owner URL in `brief/00-brief.md`, D22).
