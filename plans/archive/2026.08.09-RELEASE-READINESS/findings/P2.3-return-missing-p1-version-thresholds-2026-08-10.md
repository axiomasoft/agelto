# P2.3 return evidence — missing P1 version thresholds

P2.3 requires a host-version check that reads thresholds from P1 rather than duplicating
them. The only P1 carrier, `docker/scripts/compose-preflight.sh`, runs `docker compose
version >/dev/null`; it provides no threshold. No P1 contract declares one either.

Implementing a threshold in P2.3 would create an undeclared second policy source, while
checking only command presence would not meet the stated acceptance. The exact continuation
is `$ task:plan-design 2026.08.09-RELEASE-READINESS P2.3` to nominate a P1 threshold carrier
and update the P2.3 contract before implementation resumes.
