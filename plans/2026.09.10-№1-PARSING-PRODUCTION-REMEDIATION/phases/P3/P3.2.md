### P3.2 — Сделать source/archive object write условием успешной версии

**Intent:** Исправить A6: source download и archive child создают version/status/event только после подтверждённого object write, а same-hash retry долечивает partial state идемпотентно. RAG:— (repo-grounded: `PARSING_PRODUCTION_ACCEPTANCE.md:182-194`).

**Why:** При `throw=false` `put()` может вернуть false, но DB утверждает `Downloaded`; crash между version/status/event оставляет hash-no-op, который не восстанавливается. RAG:✅ 2026-09-10 — Laravel failed-write semantics зафиксирована в `findings/00-source-synthesis.md`.

**Scope Included:** checked write false/exception paths; object existence/readability verification appropriate to disk; short DB transaction for version/status/event after object success; same-hash reconciliation of object/DB partial states; archive child parity; orphan object cleanup/deferred marker on DB failure; fault tests for each crash boundary.

**Scope Excluded:** pretending S3 and PostgreSQL share one transaction; representation writes (P3.3); retry selection (P3.1); storage vendor replacement.

**Inputs:** `phases/P3/P3.1.state.md` · `PARSING_PRODUCTION_ACCEPTANCE.md` · `findings/00-source-synthesis.md` · `phases/P2/P2.1.state.md`.

**Implementation Rules:** Object write precedes DB success; checked `false` and exception are equivalent failure. `FinalizeDocumentDownloadAction` is sole short DB transaction for version/status/event. Retry must reconcile four observable cases: neither exists, object-only, version-only/missing object, fully consistent; status `Downloaded` only in the last. Content hash deduplicates bytes, not recovery work. RAG:— (repo-grounded: `research/01-remediation-architecture.md`).

**Code Guidance:** Fault matrix injects: false put, exception put, DB exception after object, exception after version before status/event via action rollback, same-hash retry with missing object. Assert no phantom successful version/status/event and exactly-one final version/event after heal. Do not use `exists()` alone if target adapter cannot prove readable complete bytes; use a deterministic write/read or checksum contract. No `try/catch` that converts failure to success. Preserve unrelated config dirty state if present.
