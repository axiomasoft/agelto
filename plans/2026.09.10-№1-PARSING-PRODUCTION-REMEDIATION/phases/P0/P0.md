# P0 — Непрерывные исторические партиции

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: database.partitions · deployment.schema
> Live or Irreversible: no
> Audit Intent: required
> Rationale: Additive migration changes the partition-maintenance contract for fresh and existing schemas, so catalog and deployment seams require an independent phase verdict.

## Phase Context

> **Контракт фазы (contract-first).** Потребляет: RED A8 evidence и текущие partitioned tables ·
> Производит: непрерывное поддерживаемое historical→current окно на fresh/existing install и
> machine-verifiable deployment check · Границы: не меняет retention policy, timestamps доменных
> событий или набор partitioned tables без отдельного D#.

P0 устраняет инфраструктурный Blocker до любых application regressions. Scope Included: новая
additive migration для уже развёрнутых сред, динамический fresh-install contract, fallback
maintenance continuity и PostgreSQL catalog tests для всех пяти configured tables. Scope Excluded:
DEFAULT partitions, изменение retention и подмена source timestamps. RAG:— (repo-grounded:
`findings/00-source-synthesis.md`, A8).
