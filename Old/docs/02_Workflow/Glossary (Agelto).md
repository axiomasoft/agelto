# Глоссарий — Agelto

| Термин | Определение |
|:---|:---|
| **ЕИС** | Единая информационная система в сфере закупок (zakupki.gov.ru) — основной источник данных |
| **Смета** | Строительно-сметный расчет — документ с перечнем материалов, объемов и цен |
| **Лот** | Часть заказа (тендера), может содержать несколько объектов закупки |
| **Извещение** | Уведомление о закупке в ЕИС, имеет уникальный reg_number |
| **Кроулер** | Автоматизированный агент для обхода страниц ЕИС и загрузки документов |
| **Парсинг** | Извлечение структурированных данных из неструктурированных документов (PDF/Excel) |
| **Матчинг** | Семантическое сопоставление позиции из сметы с позицией из каталога поставщика |
| **Коллекция** | Номенклатурный каталог поставщика (его прайс-лист), загруженный в Agelto |
| **Лид** | Верифицированная позиция из сметы, совпадающая с продукцией поставщика |
| **Match Score** | Процент семантического совпадения позиции сметы с номенклатурой клиента |
| **КТРУ** | Каталог товаров, работ, услуг для нужд государственных и муниципальных закупок |
| **КСР** | Классификатор строительных ресурсов |
| **ОКПД2** | Общероссийский классификатор продукции по видам экономической деятельности |
| **ОКВЭД** | Общероссийский классификатор видов экономической деятельности |
| **44-ФЗ** | ФЗ о контрактной системе (государственные закупки) |
| **223-ФЗ** | ФЗ о закупках госкорпораций и субъектов естественных монополий |
| **pgvector** | PostgreSQL-расширение для хранения и поиска векторных эмбеддингов |
| **MDM** | Master Data Management — мастер-каталог строительных ресурсов Agelto |
| **OCR** | Optical Character Recognition — распознавание текста в сканированных документах |
| **NLP** | Natural Language Processing — обработка естественного языка |
| **LayoutLM** | Трансформер-модель для понимания структуры документов (таблицы, координаты) |
| **ICP** | Ideal Customer Profile — профиль идеального клиента |
| **ARPU** | Average Revenue Per User — средняя выручка с клиента в год |
| **CAC** | Customer Acquisition Cost — стоимость привлечения клиента |
| **LTV** | Lifetime Value — суммарная выручка от клиента за весь срок жизни |
| **MQL** | Marketing Qualified Lead — квалифицированный маркетинговый лид |
| **SQL** | Sales Qualified Lead — лид, готовый к продаже |
| **ЛПР** | Лицо, принимающее решение — коммерческий директор, РОП, CDO |
| **ЖБИ** | Железобетонные изделия — один из приоритетных сегментов ICP |
| **Zero-Search** | Концепция Agelto: менеджеру не нужно вводить запросы — система ищет сама |
| **Deep Parsing Pipeline** | Конвейер глубокого парсинга: загрузка → OCR/AI → извлечение → нормализация |
| **Fingerprint** | Хеш файла для отслеживания изменений: md5(имя + размер + дата изменения) |
| **DocumentAnalysis** | Сущность Platform-модуля: задание на AI-анализ документа |
| **PromptRule** | Настраиваемое правило для AI-запроса (шаг, контент, версия, приоритет) |
| **Platform** | Ключевой модуль системы: кроулеры, парсинг, AI-анализ, прокси |
| **Eis** | Модуль интеграции с zakupki.gov.ru |
| **Sys** | Инфраструктурный модуль: прокси-пул, логирование |
| **НМЦК** | Начальная (максимальная) цена контракта |
| **ЛСР** | Локальный сметный расчёт — форма строительной сметы |
| **Reg_number** | Уникальный реестровый номер закупки в ЕИС (ключ дедупликации) |
| **Победитель** | Участник, определённый в протоколе подведения итогов; фактический покупатель материалов по смете (см. [[Procurement_Lifecycle]]) |
| **Протокол подведения итогов** | Официальный документ ЕИС с результатом закупки и победителем (ИНН, итоговая цена, дата) |
| **Уклонение** | Победитель не подписал контракт в срок; публикуется «протокол об уклонении» → контракт со 2-м участником |
| **Несостоявшаяся закупка** | Не выполнены условия конкуренции (нет/мало заявок, все отклонены) → возможна повторная |
| **Единственный поставщик** | Неконкурентная закупка (ст.93 44-ФЗ); победитель известен заранее |
| **Реестр контрактов** | Раздел ЕИС с заключёнными контрактами и сведениями об их исполнении/расторжении |
| **РНП** | Реестр недобросовестных поставщиков |
| **ЕРУЗ** | Единый реестр участников закупок |
| **ФАС** | Федеральная антимонопольная служба — рассматривает жалобы по закупкам |
